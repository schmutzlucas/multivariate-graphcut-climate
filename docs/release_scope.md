# Scientific scope

The software contains the article's distributions, Hellinger/LDR scores,
periodic latitude-weighted graph-cut callbacks, ensemble baselines, native
calendar readers, precipitation QC, support builders, run/evaluation/sensitivity
workflows and accepted figure/table renderers. Compact data support all selected
article figures/tables without raw climate data. The native optimizer and the
prepared climate files are external requirements; the exact supports are included.

The publication includes only the accepted corrected cohorts, scientific source,
necessary configurations, small reusable tests/fixtures, reference documentation
and publication products. The public file manifest defines the complete approved
archive contents. Temporary outputs, private verification evidence, source-review
records and development-only investigations have no place in this repository
or its history. Original research history remains in its separate repository.

The purpose is faithful software publication, not a mathematical redesign.
Default scientific periods, PMF sizes, costs, model exclusions, transformations
and main regularization are preserved. File hashes of sanitized metadata and
documented workflow/interface changes identify the new publication copy.
