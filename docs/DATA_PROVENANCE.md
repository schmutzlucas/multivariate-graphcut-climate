# Data availability and provenance

`data/DATA_MANIFEST.csv` (generated by `tools/build_data_manifest.py`) is the
machine-readable inventory. Each row has a category, asset, description, size,
SHA-256 where known, provenance, access route and status. An empty hash or DOI
means *unknown*, never *verified*.

## 1. Included in this repository (`1_included`)

| Asset | Content | Used by |
| --- | --- | --- |
| `results/era5/` | unrounded ERA5 scores (`summary_long.csv`), Hellinger/LDR fields and mean-bias fields | Tables 2–3, Figs. 1–2 renderers |
| `results/perfect_model/` | 450 reference-wise PME scores, pooled scores, boxplot data, 11 density-curve caches | Figs. 3–5, A2, S1–S5; Tables B1–B2 |
| `results/histogram_resolution/` | cellwise split-sample rank correlations, global means (k=4–12) | Fig. A1 |
| `results/spatial_regularisation/` | six λ label maps, fragmentation, A3 metrics | Figs. 6, A3 |
| `data/supports/` | exact production histogram supports (ERA5, PME) | Level 3 runs |
| `publication/figures/`, `publication/tables/` | assets exactly as in the manuscript | comparison references |
| `data/metadata/`, `data/*.json` | source identities, prepared-input checksums, cohort identities, ERA5 cohort comparison | provenance |
| `tests/fixtures/era5_production_patch.rds` | 4×2-cell crop of production PMFs | regression tests |

Every numerical asset is checksummed in a directory `manifest.csv`,
`publication/SHA256SUMS` and `data/DATA_MANIFEST.csv`. CSV values keep full
double precision. The RDS results and supports are **metadata-redacted copies**:
private storage paths were removed, and scientific arrays, coordinates, labels
and remaining metadata are unchanged. Their file hashes therefore differ from the
research originals. `data/cohort_provenance.json` and
`data/supports/manifest.csv` record the original identities.

Numerical cohort: all included results come from the **corrected October 2026
cohort** (calendar-complete inputs, non-negative precipitation QC, UTC-day ERA5
precipitation, exact-scope supports). That cohort produced the numbers in the
final manuscript. The only article items not rendered from it are the published
ERA5 maps (Figs. 1–2); see [KNOWN_ISSUES.md](KNOWN_ISSUES.md).

These DOIs identify the **source collections**, not the author's prepared files.
The exact model, experiment (historical/SSP5-8.5), member, grid and version used
for each prepared file are in `data/metadata/source_manifest.csv`. Some
historical versions may no longer be served; see the qualifications below.

## 3. Required for full reproduction but not publicly archived (`3_required_not_archived`)

- 69 prepared daily files (23 datasets × `pr`, `tas`, `psl`; 1° grid; ~803 GB),
  each listed with filename, bytes and SHA-256. They can be rebuilt from category 2
  with [DATA_PREPROCESSING.md](DATA_PREPROCESSING.md). A rebuild is a
  methodological replication unless its checksums match.
- The ERA5 workspace (~32 GiB) and PME result bundles/checkpoints. Only needed to
  re-evaluate saved solutions; all article diagnostics are already included in
  compact form.

No public persistent location has been established for these files. The author
has not yet decided on an access route.
