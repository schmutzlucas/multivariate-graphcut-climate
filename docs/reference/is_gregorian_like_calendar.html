Description

Identify the calendars eligible for the modern Gregorian decoder

Usage

is_gregorian_like_calendar(calendar)

Arguments

calendar

Character vector of canonical calendar names.

Value

Logical vector, TRUE only for standard or proleptic_gregorian.

Examples
