compute_mmm_pdfR Documentation

Average candidate PMFs with equal model weight to form D-MMM

Description

Average candidate PMFs with equal model weight to form D-MMM

Usage

compute_mmm_pdf(pdf_models)

Arguments

pdf_models

Normalised nonnegative finite PMFs, lon x lat x bins x models.

Value

Lon x lat x bins arithmetic mean. Models, not their sample counts, have equal weight. Invalid candidate PMFs raise an error before averaging.

Examples

compute_mmm_pdf(array(c(.2,.8,.4,.6),c(1,1,2,2)))
