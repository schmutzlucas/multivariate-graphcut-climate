extract_gc_mean_fieldR Documentation

Extract selected candidate means from a reference-first mean array

Description

Extract selected candidate means from a reference-first mean array

Usage

extract_gc_mean_field(mean_array, gc_labels)

Arguments

mean_array

Numeric longitude x latitude x models array, reference first.

gc_labels

Finite integer longitude x latitude candidate labels in 1..(number of full models minus one).

Value

Longitude x latitude matrix selecting full model index label+1. Missing field values propagate; invalid labels or mismatched grids error.
