precipitation_qc_statisticsR Documentation

Collect additive raw-precipitation quality-control statistics

Description

Collect additive raw-precipitation quality-control statistics

Usage

precipitation_qc_statistics(values)

Arguments

values

Numeric physical precipitation vector/array before QC.

Value

Named list with counts, extrema, raw/corrected sums and total absolute correction. Finite negatives alone are changed. Missing and infinite values are separately counted; an empty finite sample has missing extrema. These sufficient statistics can be merged across chunks without pooling means. Counters use doubles so global 150-year grids do not overflow R's 32-bit integers; integer counts remain exact below 2^53 observations.
