compute_model_pdfs_fractional_optimizedR Documentation

Build one model's PMFs using shared nested bin indices and latitude blocks

Description

Uses exactly the supplied support, never estimates it per reference. Fast histogram grids are nested where their resolutions permit; floating-edge snapping follows equal_width_bin_index(). Date keys across variables must agree. A latitude block bounds raw input memory, not the final retained PMF arrays.

Usage

compute_model_pdfs_fractional_optimized(
  model,
  variables,
  data_dir,
  year_present,
  year_future,
  lon,
  lat,
  range_var,
  season_start_md,
  season_end_md,
  pdf2_names,
  nbins3d,
  nbins2d,
  nbins1d,
  strict_time_checks,
  season_selection_mode,
  time_decode_mode,
  requested_year_policy,
  diagnostics,
  verbose,
  compute_hist_nd_fun = NULL,
  profile = FALSE,
  spatial_block_size = NULL
)

Arguments

model

Single prepared model identifier.

variables

Exactly c("pr", "tas", "psl"), in this order.

data_dir

Prepared data root unless an input registry is active.

year_present, year_future

Requested calibration/evaluation year vectors.

lon, lat

Ordered coordinate vectors, matched without interpolation.

range_var

Common [lon,lat,3,2] support; pr is on log(1+pr) scale.

season_start_md, season_end_md

Inclusive non-leap reference month/day boundaries.

pdf2_names

Pair identifiers pr_tas, pr_psl and tas_psl.

nbins3d, nbins2d, nbins1d

Bins per variable at each diagnostic dimensionality, normally 8/16/32. No statistical discretisation choice is made here.

strict_time_checks

Whether to enforce legacy daily-time assumptions.

season_selection_mode

Auto, exact_month_day, or fractional selection.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for incomplete/unavailable years.

diagnostics

Whether detailed extraction diagnostics may be printed.

verbose

Whether to print progress and requested diagnostic tables.

compute_hist_nd_fun

Unused compatibility argument; fast count helpers are used.

profile

Compatibility profiling flag; timing is collected either way.

spatial_block_size

Maximum requested latitude positions per raw-input block. NULL or a value at least the latitude count reads complete selected cubes.

Value

List matching the legacy worker's PMFs/means/diagnostics, with additional block/bin-index timing and approximate raw-input peak-memory statistics. PMFs omit incomplete rows per diagnostic; empty cells retain legacy zero arrays. pr uses shared nonnegative QC then log1p. Its means use physical corrected observations, not a logarithm/exponential round trip.
