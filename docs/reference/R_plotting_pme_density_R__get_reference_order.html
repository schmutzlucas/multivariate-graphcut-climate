Require complete PME reference identities before pooling raw density maps

Usage

get_reference_order(

  lambda_key,
  tau_key = NULL,
  metric_type
)

Arguments

results

Compact PME result list with metadata and named method maps.

period_id

Evaluation-period key.

lambda_key

Character GC smoothness key.

tau_key

Character LDR threshold key, ignored for full Hellinger.

metric_type

Exactly full or partial, the internal LDR identifier.

Value

Metadata model order after verifying both methods contain exactly that set once. Does not silently intersect or drop missing references.
