merge_precipitation_qc_statisticsR Documentation

Merge raw-precipitation statistics over disjoint observation chunks

Description

Merge raw-precipitation statistics over disjoint observation chunks

Usage

merge_precipitation_qc_statistics(accumulated, chunk)

Arguments

accumulated

NULL for the initial chunk, or a prior statistics list.

chunk

Statistics list from precipitation_qc_statistics(). Chunks must represent disjoint samples within one model/variable/scope.

Value

Merged additive statistics with finite extrema and maximum correction. Derived fractions/means must be computed from merged sums/counts, not by averaging chunk means. Input observations are not retained.
