score_rowR Documentation

Format paired ERA5 scores and their relative improvement as a LaTeX row

Description

Format paired ERA5 scores and their relative improvement as a LaTeX row

Usage

score_row(label, vars, metric, tau = NA_real_, name = "weighted_mean")

Arguments

label

Display label, already valid LaTeX.

vars, metric

Variable-set and metric-type keys for lookup().

tau

LDR threshold or NA_real_ for ordinary Hellinger/mean-field error.

name

Metric-name key for lookup(), default weighted_mean.

Value

Character row with baseline/GC scores to three decimals and percentage gain to one decimal. Improvement is computed from unrounded values first.
