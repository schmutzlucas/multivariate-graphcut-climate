build_fractional_indices_for_yearsR Documentation

Select seasonal file indices under the fractional year-slot convention

Description

Select seasonal file indices under the fractional year-slot convention

Usage

build_fractional_indices_for_years(
  year_table,
  timestep_year,
  timestep_slot,
  selected_years,
  start_ref_doy,
  end_ref_doy,
  wraps_year_end,
  requested_year_policy = c("warn", "stop")
)

Arguments

year_table

Year diagnostics from infer_time_structure_daily().

timestep_year

Integer year label for every file record.

timestep_slot

Corresponding one-based slot under the active time mapping.

selected_years

Requested years, sorted and deduplicated before selection.

start_ref_doy

Seasonal start day on a 365-day reference year.

end_ref_doy

Seasonal end day on that reference year.

wraps_year_end

Whether to take both ends of each selected year.

requested_year_policy

Warn or stop for absent/incomplete/empty years. Warn mode uses observed maximum slot as effective length for incomplete years.

Value

List with integer indices in chronological selected-year order and a year_summary table. Errors if nothing can be selected.
