match_requested_coordinatesR Documentation

Match requested rectilinear coordinates without regridding

Description

Longitudes at least 180 are shifted once by -360 in both request and file. This handles the Article 1 0..359/-180..179 conventions, not arbitrary turns of longitude. Output indices preserve requested order, including latitude order.

Usage

match_requested_coordinates(nc_obj, dimension_info, lon, lat)

Arguments

nc_obj

Open NetCDF handle, not closed here.

dimension_info

Axis description from get_variable_dimension_info().

lon

Requested longitude vector in degrees east.

lat

Requested latitude vector in degrees north.

Value

List with integer lon_indices and lat_indices into original file axes. Missing/ambiguous coordinates raise errors.
