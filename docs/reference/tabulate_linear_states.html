tabulate_linear_statesR Documentation

Flatten and count multivariate bin states in R array order

Description

Flatten and count multivariate bin states in R array order

Usage

tabulate_linear_states(bin_indices0, nbins)

Arguments

bin_indices0

Observations x variables matrix of valid zero-based bin indices; incomplete rows are excluded. Callers supply indices below nbins.

nbins

Number of bins per variable, identical along every axis.

Details

The first variable varies fastest: for pr/tas/psl the state is b_pr + nbins*b_tas + nbins^2*b_psl. Returned counts are not normalised PMFs.

Value

Integer counts of length nbins raised to the number of variables.

Examples

tabulate_linear_states(rbind(c(0, 1), c(1, 0)), 2)
