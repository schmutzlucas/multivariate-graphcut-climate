summarize_mapR Documentation

Summarise a spatial diagnostic with the published area-weighting convention

Description

Summarise a spatial diagnostic with the published area-weighting convention

Usage

summarize_map(field, weights)

Arguments

field

Numeric field, typically a Hellinger score map.

weights

Nonnegative weights with identical shape.

Value

One-row data frame containing mean, median, population SD, IQR, 90th/95th percentiles and finite-area fraction.
