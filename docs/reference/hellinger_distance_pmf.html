hellinger_distance_pmfR Documentation

Compute the sensitivity reference helper's ordinary Hellinger distance

Description

Compute the sensitivity reference helper's ordinary Hellinger distance

Usage

hellinger_distance_pmf(p, q)

Arguments

p, q

Valid normalised PMF vectors on identical ordered bins, or NULL for an empty split. Unlike the strict public API this internal helper assumes validity.

Value

Scalar ordinary Hellinger distance, or NA_real_ when either split is NULL. No subset renormalisation, baseline percentage or latitude weighting is applied.

Examples

stopifnot(hellinger_distance_pmf(c(1,0),c(0,1)) == 1)
