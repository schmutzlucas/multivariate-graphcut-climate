assemble_era5_fourmapR Documentation

Assemble the accepted four-map geometry

Description

Assemble the accepted four-map geometry

Usage

assemble_era5_fourmap(fields, lon, lat, kind)

Arguments

fields

List of four numeric longitude x latitude matrices in row-major panel order.

lon, lat

Longitude and latitude cell centres in degrees, matching matrix axes.

kind

Diagnostic kind: distributional or bias for layouts, hellinger or bias for scales.

Value

Gtable with era5_layout metadata containing plots, fields, scales and coordinates; no numerical experiment.
