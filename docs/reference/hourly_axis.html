hourly_axisR Documentation

Validate the native ERA5 hourly precipitation grid and decode its UTC stamps

Description

Validate the native ERA5 hourly precipitation grid and decode its UTC stamps

Usage

hourly_axis(n)

Arguments

n

Open caller-owned ncdf4 handle containing tp in metres, accumulation step type, on the exact 0.25-degree longitude/descending-latitude/valid_time grid.

Value

Numeric UTC seconds since the Unix epoch. Checks declared dimensions, units and Gregorian calendar; caller separately verifies complete hourly sequences/month boundaries. Reads coordinates only and does not close n.
