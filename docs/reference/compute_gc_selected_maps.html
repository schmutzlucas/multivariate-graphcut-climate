compute_gc_selected_mapsR Documentation

Extract calibration/evaluation score maps for graph-cut-selected models

Description

Extract calibration/evaluation score maps for graph-cut-selected models

Usage

compute_gc_selected_maps(gc_result, h_dist_pres, h_dist_fut, partial_fut)

Arguments

gc_result

Solver list with integer-valued one-based label_attribution matrix.

h_dist_pres, h_dist_fut, partial_fut

Matching [lon,lat,model] calibration, ordinary evaluation and LDR evaluation score arrays, respectively.

Value

List of lon x lat matrices present, future and partial_future. Does not reoptimise labels; each cell uses its selected candidate's already computed score. Invalid label identity/shape raises an error instead of leaving NA cells.
