compute_h_maps_from_pdfsR Documentation

Evaluate D-MMM and GC PMFs on identical selected bins

Description

Evaluate D-MMM and GC PMFs on identical selected bins

Usage

compute_h_maps_from_pdfs(pdf_ref, pdf_mmm, pdf_gc, selected_indices)

Arguments

pdf_ref, pdf_mmm, pdf_gc

Valid PMF arrays indexed longitude x latitude x bins.

selected_indices

Nested longitude/latitude bin-index lists.

Value

Named list MMM and GC-0.125 of two-dimensional score maps. Restricted masses are not renormalised; empty selections retain missing scores.
