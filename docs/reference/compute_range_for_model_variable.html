compute_range_for_model_variableR Documentation

Stream one model-variable's experiment-scoped support extrema

Description

Stream one model-variable's experiment-scoped support extrema

Usage

compute_range_for_model_variable(
  model,
  variable,
  data_dir,
  years,
  lon,
  lat,
  strict_time_checks,
  season_selection_mode,
  time_decode_mode,
  requested_year_policy,
  time_chunk_size,
  read_mode,
  max_full_read_gb,
  slab_time_count
)

Arguments

model

Single prepared model identifier, resolved through registry or data_dir.

variable

Prepared variable name; pr extrema use log1p scale.

data_dir

Prepared input hierarchy root when no input registry is active.

years

Exact requested year union, not automatically the file's entire coverage.

lon, lat

Requested longitude/latitude vectors in desired output order.

strict_time_checks

Whether to enforce legacy daily-mapping assumptions.

season_selection_mode

Auto, exact_month_day, or fractional full-year selection.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for unavailable/incomplete years.

time_chunk_size

Maximum records per chunk in chunked mode.

read_mode

Full, slab, chunked, or auto. Auto compares selected-cube size with max_full_read_gb, choosing full or slab.

max_full_read_gb

Positive GiB threshold for automatic full-cube reading.

slab_time_count

Maximum records per slab in slab mode.

Value

List with lon x lat min/max matrices and input/calendar/read diagnostics. Opens/closes its own file and omits missing samples; this legacy helper alone does not certify corrected-input provenance, complete dates or physical units.
