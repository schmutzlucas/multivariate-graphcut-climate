filter_periods_from_envR Documentation

Select an explicit nonempty subset of PME periods for a limited run

Description

Select an explicit nonempty subset of PME periods for a limited run

Usage

filter_periods_from_env(periods)

Arguments

periods

Configured period table with unique period_id values.

Value

All rows when PME_PERIODS is unset/empty, otherwise rows in the comma-separated requested order. Unknown, duplicate or blank-only selections raise an error; a limited run must not silently execute zero/repeated periods.
