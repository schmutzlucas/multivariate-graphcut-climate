ldr_hellinger_scoreR Documentation

Compute non-renormalised LDR Hellinger score

Description

Compute non-renormalised LDR Hellinger score

Usage

ldr_hellinger_score(reference, candidate, ell_ldr = 0.01)

Arguments

reference, candidate

Numeric normalised PMFs on identical ordered bins.

ell_ldr

Scalar threshold strictly between zero and one, usually 0.01.

Details

The selected subvectors are not renormalised. This measures an absolute contribution to squared Hellinger distance, not distance between conditional distributions. Ties and zero-reference bins follow select_ldr_indices().

Value

Scalar restricted Hellinger score on reference-selected LDR bins.

Examples

ldr_hellinger_score(c(0, 0.1, 0.9), c(0.2, 0.1, 0.7), ell_ldr = 0.01)
