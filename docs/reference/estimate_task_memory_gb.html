estimate_task_memory_gbR Documentation

Apply the support builder's heuristic per-worker memory multiplier

Description

Apply the support builder's heuristic per-worker memory multiplier

Usage

estimate_task_memory_gb(variable, cube_gb)

Arguments

variable

Prepared variable name; pr requires transformation temporaries.

cube_gb

Dense selected-cube size in GiB.

Value

Estimated GiB, using multiplier 2.2 for pr and 1.2 for other variables. This is a scheduling heuristic, not a measured or guaranteed peak-memory bound.
