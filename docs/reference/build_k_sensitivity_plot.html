build_k_sensitivity_plotR Documentation

Build the calibration rank-stability plot with truthful scope annotations

Description

Build the calibration rank-stability plot with truthful scope annotations

Usage

build_k_sensitivity_plot(result)

Arguments

result

Result list from run_k_sensitivity() with summary, rho array and metadata. Requires a finite k=8 summary point; other undefined scores may be NA.

Value

ggplot without writing files. Uses actual candidate/cell counts and calibration years; archived global input retains its published annotations. Rejects invalid/duplicate resolutions, impossible correlations or inconsistent scope metadata before rendering. Does not change any numerical result.
