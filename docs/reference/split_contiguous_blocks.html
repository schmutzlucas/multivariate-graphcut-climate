split_contiguous_blocksR Documentation

Group unique file indices into contiguous disk-read blocks

Description

Group unique file indices into contiguous disk-read blocks

Usage

split_contiguous_blocks(indices)

Arguments

indices

Numeric vector of positive finite integer indices. Unsorted input and repetitions are allowed; invalid positions raise an error.

Value

Data frame with integer start/count columns in increasing index order. Empty input returns a zero-row table. Caller order is not represented here.

Examples

split_contiguous_blocks(c(5L, 1L, 3L, 3L, 4L))
