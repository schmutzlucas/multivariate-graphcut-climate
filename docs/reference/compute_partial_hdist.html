compute_partial_hdistR Documentation

Compute restricted Hellinger scores for vectors or global PMF arrays

Description

Compute restricted Hellinger scores for vectors or global PMF arrays

Usage

compute_partial_hdist(pdf_ref, pdf_model, selected_indices)

Arguments

pdf_ref

Reference PMF vector, or array longitude x latitude x bins.

pdf_model

Candidate vector; bins x models matrix for a vector reference; or longitude x latitude x bins array with an optional fourth model axis.

selected_indices

One-based bin indices for a single location, or nested lists selected_indices[[longitude]][[latitude]] for a global array.

Details

Divides the square-root sum by sqrt(2) without renormalising selected masses. Selecting all bins gives ordinary Hellinger distance. Callers must supply common bins, valid masses and consistent selected indices.

Value

Scalar or model vector for vector inputs; longitude x latitude x models array for grid inputs, retaining a singleton model dimension. Empty selections return NA rather than silently returning a zero score.

Examples

compute_partial_hdist(c(0.2, 0.8), c(0.3, 0.7), 1:2)
