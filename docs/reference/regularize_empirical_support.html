regularize_empirical_supportR Documentation

Make constant empirical supports valid without forcing minima to zero

Description

Make constant empirical supports valid without forcing minima to zero

Usage

regularize_empirical_support(lower, upper, variable)

Arguments

lower, upper

Numeric arrays of empirical lower/upper bounds with the same shape. Jointly missing bounds are retained, not fabricated.

variable

Variable name; precipitation minima must be nonnegative.

Value

List min, max, constant and expansion. The empirical minimum is unchanged. For finite constant cells only, the upper bound is increased by max(1e-12, 64 * machine epsilon * max(1, abs(min))). On the log-precipitation scale this is an explicit numerical envelope around a point mass; identical observations remain in the first bin. Missing/constant cells are reported by production aggregation. Inconsistent, infinite or reversed bounds fail.
