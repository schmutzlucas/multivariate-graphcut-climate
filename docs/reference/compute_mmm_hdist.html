compute_mmm_hdistR Documentation

Evaluate ordinary Hellinger distance from a reference to D-MMM

Description

Evaluate ordinary Hellinger distance from a reference to D-MMM

Usage

compute_mmm_hdist(pdf_ref, pdf_models, mmm_pdf = NULL)

Arguments

pdf_ref

Reference PMFs, lon x lat x bins, normalised on the common support.

pdf_models

Candidate PMFs, lon x lat x bins x models, used if mmm_pdf is NULL.

mmm_pdf

Optional precomputed equal-model PMF average. Supplying it avoids recomputing the same mixture for each diagnostic/threshold; caller owns model identity.

Value

Lon x lat distance matrix, retaining singleton spatial axes. Invalid masses fail rather than converting a NaN distance to a perfect score of zero.
