compute_mmm_partial_hdistR Documentation

Evaluate non-renormalised LDR Hellinger score from a reference to D-MMM

Description

Evaluate non-renormalised LDR Hellinger score from a reference to D-MMM

Usage

compute_mmm_partial_hdist(
  pdf_ref,
  pdf_models,
  selected_indices,
  mmm_pdf = NULL
)

Arguments

pdf_ref

Reference PMFs, lon x lat x bins, normalised on the common support.

pdf_models

Candidate PMFs, lon x lat x bins x models, used if mmm_pdf is NULL.

selected_indices

Nested list indexed longitude then latitude, containing valid one-based reference-selected bin indices. Empty selections are not valid here.

mmm_pdf

Optional precomputed equal-model average, as in compute_mmm_hdist().

Value

Lon x lat score matrix with no renormalisation on selected bins. Invalid inputs/nonfinite scores raise an error; singleton spatial dimensions are retained.
