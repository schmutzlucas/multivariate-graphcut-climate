compute_mmm_gc_bias_fieldsR Documentation

Compute mean-field ensemble and selected-model biases against a reference

Description

Compute mean-field ensemble and selected-model biases against a reference

Usage

compute_mmm_gc_bias_fields(mean_future, gc_labels, var_name)

Arguments

mean_future

Named list of numeric longitude x latitude x model mean arrays. Each array has reference at index 1 and candidate models afterwards.

gc_labels

Finite integer longitude x latitude matrix indexing candidates from 1, so label k selects full-array model k+1.

var_name

Scalar character variable key in mean_future.

Value

List bias_mmm and bias_gc of longitude x latitude matrices, each method minus reference. The MMM is an equal-model mean; missing model values propagate. No precipitation/unit conversion is performed and invalid labels raise an error.
