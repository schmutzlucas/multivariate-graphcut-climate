normalize_calendar_nameR Documentation

Canonicalise the supported CF calendar names

Description

Canonicalise the supported CF calendar names

Usage

normalize_calendar_name(calendar_raw)

Arguments

calendar_raw

Raw character calendar attribute; only its first value is used.

Value

One of standard, proleptic_gregorian, julian, 360_day, 365_day, 366_day, or unknown. Missing, blank or non-character attributes default to standard.

Examples

stopifnot(normalize_calendar_name("noleap") == "365_day")
