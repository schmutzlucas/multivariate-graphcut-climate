era5_map_dataR Documentation

Lay out cached fields with wrapped longitude coordinates

Description

Lay out cached fields with wrapped longitude coordinates

Usage

era5_map_data(field, lon, lat)

Arguments

field

Numeric longitude x latitude matrix; supplied values are not normalised or imputed.

lon, lat

Longitude and latitude cell centres in degrees, matching matrix axes.

Value

Data frame with longitude, latitude, wrapped longitude and unchanged values; shape mismatch fails.
