graph_cut_energyR Documentation

Evaluate the Article 1 graph-cut energy independently in double precision

Description

Evaluate the Article 1 graph-cut energy independently in double precision

Usage

graph_cut_energy(
  labels,
  calibration_h,
  target_pmfs,
  lat,
  lambda = 0.125,
  weight_data = 1
)

Arguments

labels

One-based integer-valued longitude x latitude label matrix.

calibration_h

Nonnegative longitude x latitude x models unary distances.

target_pmfs

Normalised longitude x latitude x bins x models PMFs.

lat

Latitude centres in degrees north, matching the second array axis.

lambda

Nonnegative smoothness multiplier, normally 0.125.

weight_data

Nonnegative multiplier of the unary term, normally one.

Details

The seam is the mean endpoint cosine weight times the sum of endpoint Hellinger distances between the edge labels' candidate PMFs. This R reference does not optimise labels and is not bit-identical to native float arithmetic.

Value

Named numeric vector data, smooth and total, including their multipliers.

Examples

graph_cut_energy(matrix(1, 3, 2), array(0.1, c(3, 2, 2)),
                 array(0.5, c(3, 2, 2, 2)), c(-30, 30))
