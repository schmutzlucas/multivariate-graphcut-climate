checkpoint_path_forR Documentation

Build the period/reference PME checkpoint filename

Description

Build the period/reference PME checkpoint filename

Usage

checkpoint_path_for(checkpoint_dir, period_id, ref_index, ref_name)

Arguments

checkpoint_dir

Checkpoint root.

period_id

Target period key.

ref_index

One-based reference position in the full ordered model list.

ref_name

Exact model identifier; sanitised only for the filename.

Value

Path under checkpoint_dir/period_id with index and model name. Does not create directories or prove compatibility of any existing payload.
