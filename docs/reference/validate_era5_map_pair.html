validate_era5_map_pairR Documentation

Validate paired regular-grid maps before constructing plotting coordinates

Description

Validate paired regular-grid maps before constructing plotting coordinates

Usage

validate_era5_map_pair(baseline, candidate, lon, lat, limits)

Arguments

baseline, candidate

Numeric longitude x latitude matrices with identical dimensions. Missing values are permitted; infinities are rejected.

lon, lat

Finite distinct grid centres matching the matrix dimensions. Longitude lies in [-180,360) without duplicated periodic cells; latitude is in [-90,90]. Callers supply the regular cylindrical Article 1 grid.

limits

Two finite strictly increasing colour-scale endpoints.

Value

TRUE invisibly, or an error for incompatible/ambiguous map identities.
