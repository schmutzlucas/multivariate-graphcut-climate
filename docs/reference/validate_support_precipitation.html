validate_support_precipitationR Documentation

Verify a historical retained-negative exception, not current ingestion QC

Description

Verify a historical retained-negative exception, not current ingestion QC

Usage

validate_support_precipitation(values, model, sha256, exception = NULL)

Arguments

values

Nonempty numeric precipitation array/vector in mm per day.

model

Prepared model identifier.

sha256

Verified whole-input SHA-256 supplied by the calling scanner.

exception

NULL for strict nonnegativity, or a reviewed list containing model, sha256, minimum and action equal to retain_unchanged. The minimum must lie strictly above -1 and no higher than zero.

Value

Number of negative observations, invisibly. Never modifies values, clips, converts units or changes the production precipitation transform. Nonfinite values, mismatched exceptions and out-of-bound negatives stop. Acceptance is a numerical preparation qualification, not physical validation. Retained only to interpret historical receipts. Current production reads use precipitation_qc() instead; this function does not implement the QC rerun.
