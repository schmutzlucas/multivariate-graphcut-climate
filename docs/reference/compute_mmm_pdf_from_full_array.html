compute_mmm_pdf_from_full_arrayR Documentation

Build an equal-model distributional mean without filling missing PMF masses

Description

Build an equal-model distributional mean without filling missing PMF masses

Usage

compute_mmm_pdf_from_full_array(pdf_full)

Arguments

pdf_full

Numeric longitude x latitude x bins x models array, reference first and at least one candidate model afterwards.

Value

Longitude x latitude x bins candidate-mean PMF array. Missing values propagate: bin-wise available-model mixing could produce a nonnormalised PMF.
