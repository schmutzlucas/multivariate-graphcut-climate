Pool checked per-input extrema into separate ERA5 and common PME supports

Description

Pool checked per-input extrema into separate ERA5 and common PME supports

Usage

aggregate_prepared_supports(job)

Arguments

job

Parsed aggregation job with era5/pme scopes, signed cache records, input_registry_sha256, preparation_identity, new output paths, archived support paths and a new JSON report path. Bounds use the fixed 360 x 181 grid.

Value

Named era5/pme manifest invisibly. Each support contains exactly its ordered model/year scope, transforms, numerical settings and input metadata. Validates both complete supports before publishing any output; refuses overwrite. Checks cache model/variable/job/source identities and dimensions, not just their filenames. No raw inputs are changed or experiments started. Missing pooled cells fail with explicit locations. Constant empirical bounds preserve their minimum and use the documented upper-only numerical envelope.
