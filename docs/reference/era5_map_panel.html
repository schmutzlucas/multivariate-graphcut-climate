era5_map_panelR Documentation

Render a cached regular-grid diagnostic panel

Description

Render a cached regular-grid diagnostic panel

Usage

era5_map_panel(
  field,
  lon,
  lat,
  kind,
  limits,
  left,
  bottom,
  render_mode = c("raster", "tile")
)

Arguments

field

Numeric longitude x latitude matrix; supplied values are not normalised or imputed.

lon, lat

Longitude and latitude cell centres in degrees, matching matrix axes.

kind

Diagnostic kind: distributional or bias for layouts, hellinger or bias for scales.

limits

Numeric two-element colour limits in the diagnostic units.

left, bottom

Logical flags controlling visible latitude and longitude axes.

render_mode

Raster (default) or tile primitive; changes rendering only, not arrays, colours or geometry.

Value

ggplot object with unchanged data and scales; raster fields prevent PDF seams, while overlays stay vector.
