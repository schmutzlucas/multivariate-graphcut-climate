support_scopeR Documentation

Define exact model and year unions for experiment-specific common supports

Description

Define exact model and year unions for experiment-specific common supports

Usage

support_scope(mode = c("era5", "pme"), cfg = article1_config())

Arguments

mode

ERA5 or PME profile.

cfg

Shared Article 1 configuration.

Value

List model_names/years. ERA5 uses its reference plus 22 candidates and only calibration/evaluation windows; PME uses 15 models, calibration and all five target periods in one support, never a support per held-out reference.

Examples

stopifnot(length(support_scope("pme")$model_names)==15L)
