build_weight_matrixR Documentation

Build regular-grid cosine-latitude weights for pooled PME densities

Description

Build regular-grid cosine-latitude weights for pooled PME densities

Usage

build_weight_matrix(lon, lat)

Arguments

lon

Nonempty unique finite longitude vector, determining row count.

lat

Nonempty unique finite latitude vector in degrees north, within [-90,90].

Value

Unnormalised lon x lat cos(latitude) matrix. Assumes equal-width longitudes; this is not a general irregular-grid area calculator.
