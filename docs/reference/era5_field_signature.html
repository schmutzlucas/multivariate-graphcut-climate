era5_field_signatureR Documentation

Fingerprint cached scientific arrays and coordinates

Description

Fingerprint cached scientific arrays and coordinates

Usage

era5_field_signature(fields, lon, lat)

Arguments

fields

List of four numeric longitude x latitude matrices in row-major panel order.

lon, lat

Longitude and latitude cell centres in degrees, matching matrix axes.

Value

List of dimensions, ranges, missingness and SHA-256 identities; no fields are modified.
