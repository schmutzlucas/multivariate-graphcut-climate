article1_configR Documentation

Read the shared Article 1 scientific and runtime configuration

Description

Scientific dates, model-list paths, 8/16/32 resolutions, lambda/threshold grids and seed 1 are explicit in this function. Only input registry, data/output/ workspace roots and support paths use MVGC_* environment overrides. Loading configuration does not prove external inputs or supports are ready for a rerun.

Usage

article1_config()

Value

List of scientific parameters, model-list/support paths, data roots and the required custom solver repository/commit. No files are opened or directories created. Support paths must be supplied explicitly; no historical support is silently substituted.

Examples

stopifnot(article1_config()$nbins3d == 8L, article1_config()$seed == 1L)
