resolve_spatial_dimension_indexR Documentation

Locate the first recognised spatial axis

Description

Locate the first recognised spatial axis

Usage

resolve_spatial_dimension_index(dimension_names, candidates, label)

Arguments

dimension_names

Character vector of variable dimension names.

candidates

Accepted names for one spatial axis.

label

Axis label used if no candidate is found.

Value

One-based index of the first match; missing matches raise an error.
