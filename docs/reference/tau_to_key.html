tau_to_keyR Documentation

Format an LDR threshold for the archived PME nested-list keys

Description

Format an LDR threshold for the archived PME nested-list keys

Usage

tau_to_key(value)

Arguments

value

Numeric ell_LDR threshold (legacy argument name tau).

Value

Fixed-notation character key with at least two decimal places, e.g. "0.01", "0.10" or "0.005". This does not change the threshold used in scoring.
