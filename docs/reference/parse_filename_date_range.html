parse_filename_date_rangeR Documentation

Read the last date-range token from a climate filename

Description

Performs lexical range validation, not full calendar validation: February 30 can be legitimate for a 360-day model. Filename coverage is a discovery hint, never independent proof of the actual time-coordinate coverage.

Usage

parse_filename_date_range(file_path)

Arguments

file_path

Single path whose basename may contain YYYYMMDD-YYYYMMDD.

Value

List containing ok and start/end year, month and day integers. Missing or invalid tokens return ok=FALSE rather than throwing.

Examples

parse_filename_date_range("pr_MODEL_19500101-21001230.nc")
