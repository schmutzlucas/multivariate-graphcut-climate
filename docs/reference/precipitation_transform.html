precipitation_transformR Documentation

Apply the Article 1 nonnegative precipitation logarithm

Description

Apply the Article 1 nonnegative precipitation logarithm

Usage

precipitation_transform(values)

Arguments

values

Numeric precipitation vector/array in prepared mm/day units.

Value

log1p(precipitation_qc(values)), retaining dimensions and missing values. Infinite inputs stop explicitly. The shared transform is idempotent with respect to QC, not with respect to the logarithm: call once on physical data.

Examples

stopifnot(identical(precipitation_transform(c(-1, 0, 1)), c(0, 0, log1p(1))))
