add_distance_metricR Documentation

Build ordinary and LDR distance summaries for one variable set

Description

Build ordinary and LDR distance summaries for one variable set

Usage

add_distance_metric(
  dimension,
  variable_set,
  pdf_ref,
  pdf_models,
  pdf_mmm,
  pdf_gc,
  full_mmm_map = NULL,
  full_gc_map = NULL
)

Arguments

dimension, variable_set

Archived dimension/variable labels.

pdf_ref, pdf_mmm, pdf_gc

Normalised longitude x latitude x bins arrays.

pdf_models

Normalised longitude x latitude x bins x candidates array.

full_mmm_map, full_gc_map

Optional precomputed ordinary Hellinger maps; if either is NULL both are recomputed from PMFs.

Value

List of distance, comparison and ensemble summary data frames for ordinary Hellinger plus each tau_values threshold. Uses caller-environment area_weight_matrix, model_names and tau_values; no output files are written. Shapes/model count and complete finite normalised PMFs are validated first.
