select_ldr_indicesR Documentation

Select the manuscript's tie-inclusive low-density region

Description

Select the smallest-probability reference bins up to the first cumulative cutoff reaching tau, then include every bin tied at that cutoff.

Usage

select_ldr_indices(pdf_vector, tau = 0.1)

Arguments

pdf_vector

Numeric reference masses. Positive total mass is normalised internally. Legacy handling maps negative/nonfinite entries to zero; the strict public score API validates PMFs before calling this selector.

tau

Scalar in [0, 1), called ell_LDR in the manuscript. Tau is nominal, not a guarantee that selected mass equals the requested value.

Details

Zero-reference bins are retained. Ties may make the selected mass larger than tau. Selection uses the reference only, never candidate masses. At tau = 0 the legacy selector still retains zero bins, or all minimum-mass ties if no zero exists. ldr_hellinger_score() requires a strictly positive threshold.

Value

Sorted one-based bin indices; integer(0) if total reference mass is zero.

Examples

select_ldr_indices(c(0, 0.005, 0.005, 0.005, 0.985), tau = 0.01)
