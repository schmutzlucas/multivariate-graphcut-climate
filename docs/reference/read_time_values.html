read_time_valuesR Documentation

Read raw numeric NetCDF time coordinates

Description

Read raw numeric NetCDF time coordinates

Usage

read_time_values(nc_obj, time_dim_name)

Arguments

nc_obj

Open ncdf4 handle, not closed by this function.

time_dim_name

Name of the time coordinate/dimension.

Value

Numeric vector, preferring a variable to cached dimension values. No decoding or time-zone conversion is performed.
