weighted_rmse_against_zeroR Documentation

Compute the area-weighted root mean squared error of a bias field

Description

Compute the area-weighted root mean squared error of a bias field

Usage

weighted_rmse_against_zero(field, weights)

Arguments

field

Numeric signed bias field.

weights

Nonnegative weights with identical shape to field.

Value

Scalar sqrt(weighted mean(field^2)) on finite cells, or NA_real_.
