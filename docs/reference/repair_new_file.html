repair_new_fileR Documentation

Create a new rectilinear NetCDF container for a recovered input

Description

Create a new rectilinear NetCDF container for a recovered input

Usage

repair_new_file(
  nc,
  variable,
  path,
  times,
  units,
  calendar,
  output_units = NULL
)

Arguments

nc

Open template handle with two rectilinear spatial axes followed by time.

variable

Float/double source variable name; packed integer variables are unsupported.

path

New output path; existing files are refused.

times

Full numeric output time coordinates supplied by the recovery plan.

units

CF time-coordinate units, not climate-variable units.

calendar

Canonical CF calendar for the output time axis.

output_units

Optional climate-variable units override; defaults to its template attribute.

Value

Open writable ncdf4 handle, which the caller must close. Writes a NetCDF4 definition with compression 1, full-spatial/one-time chunks, original precision/missing value, and selected source/member/experiment/grid attributes. Does not fill the climate data or copy every template metadata attribute.
