weighted_sd_valueR Documentation

Compute the weighted population standard deviation of a field

Description

Compute the weighted population standard deviation of a field

Usage

weighted_sd_value(field, weights, transform = identity)

Arguments

field, weights

Numeric field and nonnegative weights with identical shape.

transform

Elementwise function applied before selecting finite values.

Value

Scalar population SD (no sample correction), or NA_real_ with no valid area.
