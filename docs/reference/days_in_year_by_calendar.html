days_in_year_by_calendarR Documentation

Return theoretical year lengths under a calendar rule

Description

Return theoretical year lengths under a calendar rule

Usage

days_in_year_by_calendar(year, calendar)

Arguments

year

Numeric vector of years.

calendar

One canonical name from normalize_calendar_name().

Value

Vector of year lengths. Fixed calendars return 360, 365 or 366; Julian uses divisibility by four; other names use Gregorian rules.

Examples

stopifnot(all(days_in_year_by_calendar(1999:2001, "360_day") == 360L))
