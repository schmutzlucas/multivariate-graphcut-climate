derive_nested_bin_indexR Documentation

Coarsen zero-based indices on exactly nested equal-width grids

Description

Coarsen zero-based indices on exactly nested equal-width grids

Usage

derive_nested_bin_index(finest_bin0, finest_nbins, target_nbins)

Arguments

finest_bin0

Zero-based indices on the finest grid, possibly missing.

finest_nbins

Positive integer finest-grid resolution.

target_nbins

Positive integer divisor of finest_nbins.

Value

Zero-based integer indices obtained by integer division. No samples are rebinned independently; all grids must have the same physical bounds.

Examples

derive_nested_bin_index(0:7, 8, 4)
