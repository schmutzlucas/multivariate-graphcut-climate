build_weight_matrixR Documentation

Construct Article 1 cosine-latitude weights on a regular global grid

Description

Construct Article 1 cosine-latitude weights on a regular global grid

Usage

build_weight_matrix(lon, lat)

Arguments

lon

Unique finite longitude centres in degrees; their number determines row count. Equal-width longitude cells are assumed, not checked here.

lat

Unique finite latitude centres in degrees north, in [-90,90].

Value

Lon x lat matrix with cos(latitude) repeated along longitude. Weights are unnormalised; this is not an irregular-grid cell-area calculation.

Examples

build_weight_matrix(0:2,c(-30,30))
