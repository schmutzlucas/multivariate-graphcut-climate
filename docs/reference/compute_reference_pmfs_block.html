compute_reference_pmfs_blockR Documentation

Build the R sensitivity reference PMFs for a latitude block

Description

Build the R sensitivity reference PMFs for a latitude block

Usage

compute_reference_pmfs_block(
  raw,
  model_plan,
  range_var,
  lat_positions,
  k_values
)

Arguments

raw

Named pr/tas/psl cubes, lon x local-lat x time, with transformed pr.

model_plan

Reference selected-year odd/even masks.

range_var

Full requested-grid lon x lat x variable x min/max support array.

lat_positions

Full-grid latitude positions corresponding to raw's local rows.

k_values

Integer per-variable resolutions.

Value

Named resolution list of lon x local-lat x two split list arrays. Every entry is a k^3 PMF or NULL. R verification/reference path; global production rank sensitivity uses compact native count arrays instead.
