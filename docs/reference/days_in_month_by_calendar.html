days_in_month_by_calendarR Documentation

Return theoretical month lengths with explicit scalar broadcasting

Description

Return theoretical month lengths with explicit scalar broadcasting

Usage

days_in_month_by_calendar(year, month, calendar)

Arguments

year

Finite integer years within R's integer range.

month

Finite integer months in 1 through 12. Length must equal year, or one of the two arguments must have length one.

calendar

Canonical CF calendar name; unrecognised names use Gregorian rules.

Value

Numeric or integer month lengths in input order; an empty argument yields an empty integer vector. Partial recycling is rejected.

Examples

stopifnot(all(days_in_month_by_calendar(1999:2001, 2, "standard") == c(28,29,28)))
