audit_cf_datesR Documentation

Independently decode CF dates without Gregorian coercion of fixed calendars

Description

Gregorian inputs use UTC arithmetic. Fixed calendars use year-length and month-offset arithmetic, including origin time-of-day and negative offsets. A 1e-8-day boundary tolerance is applied before flooring fixed-calendar days. This decoder labels records; it does not itself certify ordering, uniqueness, complete years or the correctness of the climate-variable values.

Usage

audit_cf_dates(values, units, calendar)

Arguments

values

Finite numeric CF time offsets.

units

Days/hours/seconds-since units string with a supported UTC origin.

calendar

Calendar name or alias: standard/proleptic Gregorian, 360_day, 365_day or 366_day. Julian and unknown calendars are not supported here.

Value

List with ok=TRUE, integer year/month/day vectors, a source label and NA error_message. Invalid coordinates/origins or unsupported calendars error.

Examples

audit_cf_dates(59,"days since 2000-01-01","360_day") # February 30
