derive_date_range_from_time_axisR Documentation

Derive fallback endpoints when no filename date range can be read

Description

Prefers the optional CF helper, then the modern Gregorian decoder. Last resort: add rounded min/max offsets to a Gregorian origin and explicitly mark the range estimated. The latter is not exact CF decoding for non-Gregorian calendars.

Usage

derive_date_range_from_time_axis(
  file_path,
  nc_obj,
  time_dim_name,
  time_values,
  time_units,
  scale_days,
  calendar,
  time_decode_mode
)

Arguments

file_path

Path used in diagnostic errors.

nc_obj

Open NetCDF handle, not closed here.

time_dim_name

Time dimension name.

time_values

Nonempty numeric time offsets.

time_units

Character CF units attribute.

scale_days

Multiplier converting offsets to days.

calendar

Canonical calendar name.

time_decode_mode

Requested auto, helpers_cf, or empirical backend.

Value

List with endpoint fields in parsed, a source label, and optional caution note. Errors if no origin can be recovered.
