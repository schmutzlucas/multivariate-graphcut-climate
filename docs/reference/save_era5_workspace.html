Save the explicit ERA5 scientific-workspace whitelist

Description

Save the explicit ERA5 scientific-workspace whitelist

Usage

save_era5_workspace(file, envir = parent.frame(), stage = c("all", "pmfs"))

Arguments

file

Destination RData path; normal R save() overwrite behaviour applies.

envir

Environment containing experiment objects, normally the global Rscript environment. Private enclosing environments of saved functions can capture extra objects; the validation driver deliberately avoids that case.

stage

Either all (the historical scientific whitelist) or pmfs (only pre-optimisation inputs, raw PMF arrays and means). The pmfs stage excludes stale score/label objects remaining in an interactive caller environment.

Value

Character names actually saved, invisibly. Missing whitelist objects are omitted. Writes an uncompressed workspace, potentially many GB, including PMFs/support/configuration/maps and the solver function but not arbitrary interactive objects. Does not create the parent directory or validate a run.
