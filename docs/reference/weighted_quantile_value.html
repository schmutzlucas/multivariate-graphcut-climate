weighted_quantile_valueR Documentation

Compute weighted empirical quantiles without interpolation

Description

Compute weighted empirical quantiles without interpolation

Usage

weighted_quantile_value(field, weights, probs, transform = identity)

Arguments

field, weights

Numeric field and nonnegative weights with identical shape.

probs

Finite numeric probabilities in [0,1], in the desired output order.

transform

Elementwise function applied before selecting finite values.

Value

Numeric vector, the first sorted value whose cumulative normalised weight reaches each probability. Returns NA entries when no valid weight remains.
