reproduction_inventoryR Documentation

Verify and inventory the compact inputs selected for Level 1 rendering

Description

Verify and inventory the compact inputs selected for Level 1 rendering

Usage

reproduction_inventory(scripts, profile = reproduction_profile())

Arguments

scripts

Nonempty selected figure/table entry-point paths.

profile

Resolved current publication compact-result profile.

Value

Data frame of exact selected input paths, sizes, SHA-256, overrides and manifest matches. Default inputs must match their archived manifests. Custom overrides are hashed but not certified as the publication cohort. Climate inputs, supports, checkpoints and large production workspaces are never read.
