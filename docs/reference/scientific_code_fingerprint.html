scientific_code_fingerprintR Documentation

Fingerprint scientific source without invalidating R caches for comments alone

Description

Fingerprint scientific source without invalidating R caches for comments alone

Usage

scientific_code_fingerprint(paths)

Arguments

paths

Nonempty distinct existing source paths, normally repository-relative.

Value

Named SHA-256 character vector. R files are parsed without source references and canonically deparsed, so ordinary comments/formatting are ignored but executable/default changes are retained. Other files (including native C++) use complete byte hashes. No source statements are evaluated.

Examples

scientific_code_fingerprint("R/metrics/ldr.R")
