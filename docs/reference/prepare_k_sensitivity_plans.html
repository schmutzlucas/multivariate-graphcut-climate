prepare_k_sensitivity_plansR Documentation

Prepare matched odd/even calibration-date read plans across model variables

Description

Prepare matched odd/even calibration-date read plans across model variables

Usage

prepare_k_sensitivity_plans(
  model_names,
  variables,
  data_dir,
  years,
  lon,
  lat,
  season_start_md = c(1, 1),
  season_end_md = c(12, 31),
  strict_time_checks = TRUE,
  season_selection_mode = "auto",
  time_decode_mode = "auto",
  requested_year_policy = "warn",
  verbose = TRUE
)

Arguments

model_names

Distinct prepared model identifiers, including the reference.

variables

Ordered pr/tas/psl identifiers.

data_dir

Prepared NetCDF hierarchy root unless a frozen registry is active.

years

Requested calibration years; record year parity defines the split.

lon, lat

Requested rectilinear coordinate vectors, without interpolation.

season_start_md, season_end_md

Inclusive non-leap reference month/day boundaries.

strict_time_checks

Whether to enforce legacy daily-mapping assumptions.

season_selection_mode

Auto, exact_month_day, or fractional selection.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for unavailable/incomplete requested years.

verbose

Whether to print per-model metadata progress.

Value

Named model list with per-variable extraction plans, selected_year, odd/even logical masks. Reads time/coordinate metadata, not climate cubes; compares date identities across variables rather than their file-local offsets.
