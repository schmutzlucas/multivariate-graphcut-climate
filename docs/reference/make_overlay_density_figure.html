make_overlay_density_figureR Documentation

Construct the five-period Article 1 PME density overlay from raw compact maps

Description

Blue shades denote D-MMM and red shades GC, with period-specific intensity. Includes an area-weighted mean table, no vertical mean markers. This raw-map renderer supports re-curating numerical curve coordinates; Level 1 publication figures normally use the compact cached curves instead of all spatial maps.

Usage

make_overlay_density_figure(
  results,
  lambda_key,
  output_base,
  save_dpi,
  metric_type = "full",
  tau_key = NULL,
  save_outputs = TRUE
)

Arguments

results

Compact PME result list with metadata, periods and complete maps.

lambda_key

GC smoothness key, normally "0.125".

output_base

Output stem for PDF/PNG, without extension. Parent directory must exist; saving can overwrite these filenames, so select a new stem for review.

save_dpi

Raster resolution passed to ggsave.

metric_type

Full ordinary Hellinger or partial internal LDR identifier.

tau_key

Character LDR threshold, used for maps and the table label; ignored in full-Hellinger mode.

save_outputs

Whether to save the 29 x 18 cm PDF and PNG; FALSE constructs the plot for numerical curve caching without writing figure files.

Value

ggplot object invisibly, with pooled density curves and a summary table. Does not run PMF estimation, graph cut or select/repair an input dataset.
