build_period_density_dataR Documentation

Stack raw spatial PME distance fields for one pooled density panel

Description

Stack raw spatial PME distance fields for one pooled density panel

Usage

build_period_density_data(
  results,
  period_id,
  lambda_key,
  tau_key,
  metric_type,
  lon,
  lat,
  weight_matrix
)

Arguments

results

Compact PME result list containing both methods for every reference.

period_id

Evaluation-period key.

lambda_key

GC smoothness key used to construct the internal GC method label.

tau_key

LDR threshold key, ignored for full Hellinger.

metric_type

Full Hellinger or partial internal LDR identifier.

lon, lat

Coordinate vectors determining expected map shape.

weight_matrix

Matching lon x lat cosine-latitude weight matrix.

Value

Data frame with method factor, value and weight. Internal MMM means D-MMM; nonfinite values/weights and negative weights are removed. This is a pooled grid-cell density, not the equal-reference distribution of relative improvements; no per-reference weight renormalisation is applied.
