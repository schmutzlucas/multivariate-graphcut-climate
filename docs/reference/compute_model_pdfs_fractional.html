Dispatch a single-model PMF computation to the selected backend

Description

Dispatch a single-model PMF computation to the selected backend

Usage

compute_model_pdfs_fractional(
  ...,
  backend = c("optimized", "legacy"),
  profile = FALSE
)

Arguments

...

Named arguments forwarded to the corresponding single-model worker.

backend

Optimized shared-index/block implementation or legacy reference.

profile

Forwarded compatibility profiling flag.

Value

The selected worker's list of PMFs, means and diagnostics. This dispatcher does not choose periods, supports, models, or a different histogram resolution.
