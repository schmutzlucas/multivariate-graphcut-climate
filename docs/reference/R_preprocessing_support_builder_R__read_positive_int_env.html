Read a positive-integer environment setting for support construction

Description

Read a positive-integer environment setting for support construction

Usage

read_positive_int_env(var_name, default_value)

Arguments

var_name

Environment-variable name.

default_value

Default positive integer when unset or invalid.

Value

Integer, warning and using the default on fractional/nonfinite/ nonpositive/out-of-range settings. Does not alter the process environment.
