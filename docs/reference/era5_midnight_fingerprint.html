era5_midnight_fingerprintR Documentation

Fingerprint the complete decoded following-midnight ERA5 precipitation map

Description

Fingerprint the complete decoded following-midnight ERA5 precipitation map

Usage

era5_midnight_fingerprint(values, utc_seconds)

Arguments

values

Numeric longitude x latitude x one-hour array, in native metres. Coordinates/units/calendar must already have passed the native-grid checks.

utc_seconds

Single finite UTC timestamp, in seconds since the Unix epoch.

Value

Lowercase SHA-256 over dimensions, decoded double values and timestamp, using R's version-2 XDR serialisation. This hashes the actual required midnight, not unused later hours or container metadata in the following monthly file. Finite negative hourly increments are fingerprinted, not silently modified; the resulting daily product separately requires nonnegative precipitation.
