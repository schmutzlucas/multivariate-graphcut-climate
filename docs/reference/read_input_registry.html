read_input_registryR Documentation

Read and validate the frozen input registry without reading climate payloads

Description

Read and validate the frozen input registry without reading climate payloads

Usage

read_input_registry(
  path = Sys.getenv("MVGC_INPUT_REGISTRY", ""),
  required_models = NULL,
  required_variables = c("pr", "tas", "psl")
)

Arguments

path

Registry JSON path, defaulting to MVGC_INPUT_REGISTRY.

required_models

Optional distinct model identifiers whose complete variable coverage must be present before starting an experiment.

required_variables

Distinct expected variables for each required model, default pr/tas/psl; only used when required_models is supplied.

Value

Parsed list with roots/inputs and any producer metadata unchanged. Checks nonempty schema, unique identities, safe relative paths, byte sizes, optional checksum syntax and requested model-variable completeness. Does not open NetCDFs, establish complete dates/units or freshly hash payloads.
