label_fragmentationR Documentation

Measure unweighted label fragmentation with cylindrical neighbours

Description

Measure unweighted label fragmentation with cylindrical neighbours

Usage

label_fragmentation(labels)

Arguments

labels

Complete longitude x latitude matrix of categorical model labels.

Details

Includes periodic longitude edges and ordinary north-south edges, with no diagonal or polar wrap. This is an edge fraction, not area-weighted patch size or the graph-cut seam energy.

Value

Percentage of undirected neighbouring cell pairs with different labels.

Examples

label_fragmentation(matrix(1, 3, 2))
