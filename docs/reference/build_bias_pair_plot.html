build_bias_pair_plotR Documentation

Render a pair of signed mean-field bias maps

Description

Render a pair of signed mean-field bias maps

Usage

build_bias_pair_plot(
  bias_mmm,
  bias_gc,
  lon,
  lat,
  limits = c(-8, 8),
  fill_name = NULL,
  left_title = "MMM",
  right_title = "GC-0.125",
  row_title = "",
  show_x_title = TRUE
)

Arguments

bias_mmm, bias_gc

Numeric longitude x latitude mean-field bias matrices. Missing cells remain missing; values beyond limits are visually squished.

lon, lat

Regular cylindrical grid centres matching the matrices.

limits

Two finite increasing shared colour-scale endpoints.

fill_name

Colour-scale title, or NULL to omit.

left_title, right_title

Scalar character method titles; empty hides.

row_title

Scalar character shared row title; empty hides.

show_x_title

Logical; include the Longitude axis title when TRUE.

Value

patchwork plot retaining the original diverging palette, shared legend, crop and typography. No unit conversion, numerical evaluation or file writing.
