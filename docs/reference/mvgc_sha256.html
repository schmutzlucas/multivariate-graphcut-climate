mvgc_sha256R Documentation

Compute a payload SHA-256 through a binary file connection

Description

Compute a payload SHA-256 through a binary file connection

Usage

mvgc_sha256(path)

Arguments

path

Path to a readable existing file, including institutional SMB paths.

Value

Lowercase hexadecimal SHA-256 string. Requires openssl, reads the complete file, closes its connection on exit, and never changes the payload.
