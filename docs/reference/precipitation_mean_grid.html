precipitation_mean_gridR Documentation

Compute original-scale precipitation means before the logarithm

Description

Compute original-scale precipitation means before the logarithm

Usage

precipitation_mean_grid(cube)

Arguments

cube

Numeric longitude x latitude x time array in prepared mm/day units.

Value

Longitude x latitude means of nonnegative corrected observations, omitting missing values. All-missing cells return NA; infinities stop. No log/exp round trip is used, so means use corrected physical observations.
