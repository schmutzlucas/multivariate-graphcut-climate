pme_scientific_settingsR Documentation

Construct a reproducible signature of the PME scientific implementation/settings

Description

Construct a reproducible signature of the PME scientific implementation/settings

Usage

pme_scientific_settings(cfg = article1_config())

Arguments

cfg

Shared experiment configuration, optionally a compact test grid.

Value

List of exact scientific parameters, canonical source fingerprints, R/platform and relevant installed software versions. Ignores ordinary R comments/formatting but not executable changes. Does not hash climate payloads; input/support provenance is checked separately.
