compute_model_pdfs_fractional_legacyR Documentation

Build one model's marginal and joint PMFs using the reference histograms

Description

Internal worker for the public multi-model entry point. Reads all selected variables for both periods before looping over cells. Precipitation uses the shared nonnegative QC then log1p; precipitation means use corrected physical observations before transformation. Missing rows are omitted separately for each marginal/joint diagnostic. Empty local samples retain zero arrays, not valid PMFs.

Usage

compute_model_pdfs_fractional_legacy(
  model,
  variables,
  data_dir,
  year_present,
  year_future,
  lon,
  lat,
  range_var,
  season_start_md,
  season_end_md,
  pdf2_names,
  nbins3d,
  nbins2d,
  nbins1d,
  strict_time_checks,
  season_selection_mode,
  time_decode_mode,
  requested_year_policy,
  diagnostics,
  verbose,
  compute_hist_nd_fun,
  profile = FALSE,
  spatial_block_size = NULL
)

Arguments

model

Single prepared model identifier.

variables

Exactly c("pr", "tas", "psl"), in this order.

data_dir

Prepared data hierarchy root, unless registry resolution is active.

year_present, year_future

Requested calibration/evaluation year vectors.

lon, lat

Ordered longitude/latitude coordinate vectors.

range_var

Common local support array [lon,lat,variable,min/max], with precipitation bounds already on the log(1+pr) scale.

season_start_md, season_end_md

Inclusive non-leap reference month/day boundaries.

pdf2_names

Pair identifiers pr_tas, pr_psl and tas_psl.

nbins3d, nbins2d, nbins1d

Positive integer bins per axis for joint, bivariate and univariate histograms respectively, normally 8/16/32.

strict_time_checks

Whether to enforce legacy daily-time assumptions.

season_selection_mode

Auto, exact_month_day, or fractional selection.

time_decode_mode

Auto, helpers_cf, or empirical time decoding.

requested_year_policy

Warn or stop for incomplete/unavailable years.

diagnostics

Whether detailed extraction diagnostics may be printed.

verbose

Whether to print progress and, if diagnostics is TRUE, tables.

compute_hist_nd_fun

Reference-compatible count callback with data, range_var and nbins arguments.

profile

Compatibility profiling flag; timing is collected either way.

spatial_block_size

Accepted for backend compatibility; ignored by this worker.

Value

List of present/future three-dimensional PMF arrays, named lists of bivariate/univariate arrays and mean matrices, plus diagnostics/timing/performance. The first variable varies fastest in flattened histogram states.
