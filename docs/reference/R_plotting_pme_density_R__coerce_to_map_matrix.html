coerce_to_map_matrixR Documentation

Resolve one raw PME density map without reinterpreting its spatial axes

Description

Resolve one raw PME density map without reinterpreting its spatial axes

Usage

coerce_to_map_matrix(map_obj, expected_dim, label)

Arguments

map_obj

Numeric matrix of the expected shape, or a dimensionless legacy vector with longitude-fastest column-major ordering.

expected_dim

Positive integer c(nlon,nlat) dimensions.

label

Scientific map identity included in an invalid-shape error.

Value

Lon x lat matrix. Wrong-shaped arrays are rejected even if total length agrees; no transposition/regridding is guessed from array size.
