inspect_fractional_seasonal_selectionR Documentation

Inspect one point's seasonal extraction and its time diagnostics

Description

Inspect one point's seasonal extraction and its time diagnostics

Usage

inspect_fractional_seasonal_selection(
  nc_file,
  variable,
  year_span,
  season_start_md,
  season_end_md,
  lon_target = NULL,
  lat_target = NULL,
  strict_time_checks = TRUE,
  season_selection_mode = c("auto", "exact_month_day", "fractional"),
  time_decode_mode = c("auto", "helpers_cf", "empirical"),
  requested_year_policy = c("warn", "stop"),
  verbose = TRUE
)

Arguments

nc_file

Path to a prepared daily NetCDF file.

variable

Variable name to inspect.

year_span

Requested years, sorted/deduplicated before extraction.

season_start_md, season_end_md

Inclusive non-leap reference month/day boundaries.

lon_target, lat_target

Scalar coordinates; missing coordinates default independently to the first corresponding file coordinate.

strict_time_checks

Whether to enforce daily-mapping assumptions.

season_selection_mode

Auto, exact_month_day, or fractional selection.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for unavailable/incomplete years.

verbose

Whether to print the diagnostic tables.

Value

Extraction diagnostics list. This convenience inspector reads the selected climate values at one point; it is not metadata-only.
