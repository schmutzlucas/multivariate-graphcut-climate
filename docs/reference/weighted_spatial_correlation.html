weighted_spatial_correlationR Documentation

Compute the weighted Pearson spatial correlation on common finite cells

Description

Compute the weighted Pearson spatial correlation on common finite cells

Usage

weighted_spatial_correlation(field, ref, weights)

Arguments

field, ref

Numeric spatial fields with identical shape.

weights

Nonnegative weights of the same shape.

Value

Scalar correlation; NA_real_ with no common area or either field constant.
