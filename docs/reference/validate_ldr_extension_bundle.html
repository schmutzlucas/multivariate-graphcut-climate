validate_ldr_extension_bundleR Documentation

Validate saved PME identities and labels before extending LDR diagnostics

Description

Validate saved PME identities and labels before extending LDR diagnostics

Usage

validate_ldr_extension_bundle(bundle, cfg = article1_config())

Arguments

bundle

Compact PME list with meta, periods, GC_result_list and existing ordinary/LDR result collections. A complete one-percent baseline is required.

cfg

Shared Article 1 configuration; compact grids/model lists may be supplied explicitly by tests. Publication defaults remain 15 references/8^3 bins.

Value

TRUE invisibly after exact configured model/grid/variable/year/period checks, integer candidate-label checks and finite existing one-percent score checks. Does not approve climate payloads or recompute scores.
