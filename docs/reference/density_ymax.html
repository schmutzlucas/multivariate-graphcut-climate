density_ymaxR Documentation

Find the maximum kernel-density height for a common overlay axis

Description

Find the maximum kernel-density height for a common overlay axis

Usage

density_ymax(df_period, method_colors)

Arguments

df_period

Stacked method/value/weight samples for one period.

method_colors

Named colour vector keyed by internal method labels.

Value

Scalar maximum of ggplot2's evaluated area-weighted density curves, using adjust=1 and bounds/limits [0,1]. Does not save or display the plot.
