validate_pmfR Documentation

Validate a probability mass function without modifying it

Description

Validate a probability mass function without modifying it

Usage

validate_pmf(p, tolerance = 1e-10)

Arguments

p

Numeric nonempty vector of finite nonnegative masses.

tolerance

Allowed absolute deviation of total mass from one.

Value

p invisibly; raises an error for an invalid PMF. No renormalisation occurs.

Examples

validate_pmf(c(0, 0.25, 0.75))
