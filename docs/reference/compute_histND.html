compute_histNDR Documentation

Compute N-dimensional Histogram

Description

This function computes an n-dimensional histogram from a given dataset, where each variable is assigned to a specific bin based on the provided range and number of bins. The function returns a flattened vector representing the histogram counts for each combination of bins across all variables.

Usage

compute_histND(data, range_var, nbins)

Arguments

data

A matrix where each column represents a variable and each row is an observation.

range_var

A matrix of dimension '[n_vars, 2]' that defines the minimum and maximum values for each variable. The first column corresponds to the minimum values, and the second column corresponds to the maximum values.

nbins

A numeric value specifying the number of bins for each variable.

Details

These are integer counts, not normalised PMFs. The first variable's bin varies fastest in the flattened array. Out-of-support values saturate into edge bins; rows containing missing observations do not contribute.

Value

A numeric vector representing the flattened n-dimensional histogram. The vector has length equal to 'nbins^n_vars', where 'n_vars' is the number of variables.

Examples

# Example data with two variables
data <- matrix(seq(-1, 1, length.out = 100), ncol = 2) # 50 paired observations
range_var <- cbind(c(-3, -3), c(3, 3)) # Min/max columns
nbins <- 10  # Number of bins per variable

# Compute the n-dimensional histogram
hist_vector <- compute_histND(data, range_var, nbins)
