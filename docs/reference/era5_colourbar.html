era5_colourbarR Documentation

Build a physical colourbar from the map scale

Description

Build a physical colourbar from the map scale

Usage

era5_colourbar(scale, row, name, unit_label = NULL)

Arguments

scale

ggplot2 fill scale already trained for the panel.

row

One-based diagnostic row (1 or 2).

name

Grid grob identifier.

unit_label

Optional text/plotmath physical-unit label.

Value

Grid tree with raster colour strip, vector ticks and unit label; no device opened.
