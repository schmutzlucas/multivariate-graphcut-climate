Description

Resolve an exact model-variable payload from the active frozen registry

Usage

registry_input_file(model, variable, required_years)

Arguments

model, variable

Single model/variable identifiers, matched exactly.

required_years

Nonempty finite integer years; optional recorded endpoint years must bracket the request. This endpoint test does not prove no dates are missing.

Value

Exact existing payload path after schema/path/size/endpoint checks. Never falls back to directory discovery. Full SHA-256 verification belongs to preparation and the explicit prepared-run launcher, not every point read.
