Description

Build the shared two-method header for a four-map figure

Usage

make_column_title_grob(left_title = "MMM", right_title = "GC-0.125")

Arguments

left_title, right_title

Scalar character method labels. MMM denotes the mean-field baseline; distributional callers explicitly supply D-MMM.

Value

grid tree containing two 13-point titles at the fixed manuscript positions.
