coerce_to_map_matrixR Documentation

Resolve one PME map without silently reinterpreting a different grid shape

Description

Resolve one PME map without silently reinterpreting a different grid shape

Usage

coerce_to_map_matrix(map_obj, expected_dim, label)

Arguments

map_obj

Numeric matrix of the expected shape, or a dimensionless legacy vector already in longitude-fastest column-major order.

expected_dim

Positive integer c(nlon,nlat) shape.

label

Map identity used in error messages.

Value

Lon x lat matrix. A matrix/array with a different shape fails even when its element count matches; only a raw vector can be reshaped.
