repair_axisR Documentation

Decode and validate an ordered, unique daily-date CF axis

Description

Decode and validate an ordered, unique daily-date CF axis

Usage

repair_axis(nc)

Arguments

nc

Open NetCDF handle with supported CF time units and calendar attributes.

Value

List of time name/values/units/calendar, independently decoded date components and YYYY-MM-DD keys. Duplicate or non-increasing dates fail; completeness and a daily timestamp phase are checked separately by the preparation workflow.
