build_metric_means_from_rdsR Documentation

Summarise paired spatial PME scores separately for each reference and period

Description

First average each method's distance field with the supplied spatial weights, then compute 100 * (H_D-MMM - H_GC) / H_D-MMM for that reference. This is not an average of local percentage ratios and does not pool references. Both methods must have the same valid-cell mask; matching missing cells retain the historical common-area omission rule. Positive improvement favours GC.

Usage

build_metric_means_from_rds(
  results,
  metric_type,
  metric_label,
  lambda_key,
  tau_key,
  weight_matrix
)

Arguments

results

Compact PME result list with periods, metadata and method maps.

metric_type

Full ordinary Hellinger or partial internal LDR identifier.

metric_label

Human-readable label copied into each output row.

lambda_key

GC smoothness map key, normally "0.125".

tau_key

LDR threshold map key, ignored for full Hellinger.

weight_matrix

Finite nonnegative lon x lat weights with positive total.

Value

Data frame with metric_label, period_id, period, reference, H_MMM, H_GC, delta_H and rel_improvement in percent. H_MMM denotes D-MMM internally. Requires complete reference sets, distinct periods, correct map shapes and finite paired means with a strictly positive D-MMM denominator.
