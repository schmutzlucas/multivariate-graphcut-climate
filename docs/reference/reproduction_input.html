reproduction_inputR Documentation

Select one Level 1 input while preserving explicit environment overrides

Description

Select one Level 1 input while preserving explicit environment overrides

Usage

reproduction_input(key, profile = reproduction_profile())

Arguments

key

One named input from reproduction_profile()$paths.

profile

Resolved compact-result profile, defaulting to the selected profile.

Value

Path from the named override, or the selected profile. An explicitly empty override fails; missing files never trigger selection of another cohort.
