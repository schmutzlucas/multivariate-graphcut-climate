compute_nd_pdf_multi_seasonalR Documentation

Build calibration and evaluation PMFs on one fixed support for multiple models

Description

Validates common grid/support/model configuration, dispatches model workers, then assembles arrays with a final model axis. This is a memory-intensive computation: latitude blocking limits raw input cubes, not retained outputs. Missing observations are excluded per marginal/joint sample; all-zero local histograms remain zero under the legacy convention and must not be fed to a solver as normalised PMFs. No new support or reference-specific support is made.

Usage

compute_nd_pdf_multi_seasonal(
  variables,
  model_names,
  data_dir,
  year_present,
  year_future,
  lon,
  lat,
  range_var,
  season_start_md = c(4, 15),
  season_end_md = c(10, 14),
  nbins3d = 8,
  nbins2d = 16,
  nbins1d = 32,
  workers = 4,
  strict_time_checks = TRUE,
  diagnostics = FALSE,
  verbose = FALSE,
  season_selection_mode = c("auto", "exact_month_day", "fractional"),
  time_decode_mode = c("auto", "helpers_cf", "empirical"),
  requested_year_policy = c("warn", "stop"),
  pmf_backend = c("optimized", "legacy"),
  profile = FALSE,
  spatial_block_size = 8L
)

Arguments

variables

Exactly c("pr", "tas", "psl"), in that order.

model_names

Distinct nonempty model identifiers in desired output order.

data_dir

Prepared daily NetCDF root; registry resolution takes precedence.

year_present, year_future

Nonempty finite integer calibration/evaluation years.

lon, lat

Nonempty unique finite longitude/latitude coordinate vectors.

range_var

Finite strictly increasing bounds [lon,lat,3,2], aligned with the requested grid; pr bounds must already represent log(1+pr).

season_start_md, season_end_md

Inclusive month/day boundaries on a 365-day reference year. Helper defaults are seasonal; Article 1 entry points explicitly pass January 1 through December 31, so do not infer production dates from defaults.

nbins3d, nbins2d, nbins1d

Positive integer bins per variable, default 8/16/32.

workers

Positive integer model-worker count. Uses multicore on Unix and multisession elsewhere, restoring the previous future plan on exit.

strict_time_checks

Whether to enforce the legacy daily-mapping assumptions.

diagnostics

Whether detailed model extraction diagnostics may be printed.

verbose

Whether workers print progress and requested diagnostics.

season_selection_mode

Auto, exact_month_day, or fractional seasonal selection.

time_decode_mode

Auto, helpers_cf, or empirical time decoding.

requested_year_policy

Warn or stop for missing/incomplete requested years; warn preserves the original experiment behaviour, not an input repair policy.

pmf_backend

Optimized shared-index/blocked worker or legacy reference worker.

profile

Compatibility profiling flag forwarded to each model worker.

spatial_block_size

Latitude positions per optimized raw-input block; NULL disables blocked reads. Defaults to eight, independently of the histogram bins.

Value

List pdf3/pdf2/pdf1/mean, each with present/future outputs; arrays have longitude x latitude x bins x models, mean arrays omit the bin axis. Bivariate/univariate/mean entries are named lists. Also returns diagnostics, calendars, timing/performance lists by model, and the selected pmf_backend.
