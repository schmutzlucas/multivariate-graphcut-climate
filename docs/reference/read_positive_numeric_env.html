read_positive_numeric_envR Documentation

Read a finite positive numeric resource setting

Description

Read a finite positive numeric resource setting

Usage

read_positive_numeric_env(var_name, default_value)

Arguments

var_name

Environment-variable name, usually a support memory-budget setting.

default_value

Finite positive numeric default supplied by the caller.

Value

Numeric value; unset/empty settings use the default, invalid nonempty settings warn and use it. Does not modify the environment or allocate memory.
