extract_fractional_variable_dataR Documentation

Plan or read calibration and evaluation records for one climate variable

Description

Opens and closes its own file. Auto season selection prefers decoded inclusive month/day boundaries and warns before falling back to fractional year slots. Precipitation is nonnegative-QC'd by the shared disk reader; its logarithmic transformation belongs to the PMF layer. Other physical variables are unchanged. Selection diagnostics distinguish filenames, observed record slots and decoded date identities. Callers aligning variables must compare selected date keys, not file-local indices, because file start years may differ.

Usage

extract_fractional_variable_data(
  file_path,
  variable,
  lon,
  lat,
  year_present,
  year_future,
  season_start_md,
  season_end_md,
  strict_time_checks = TRUE,
  season_selection_mode = c("auto", "exact_month_day", "fractional"),
  time_decode_mode = c("auto", "helpers_cf", "empirical"),
  requested_year_policy = c("warn", "stop"),
  read_data = TRUE
)

Arguments

file_path

Path to one prepared rectilinear daily NetCDF file.

variable

Name of its three-dimensional climate variable.

lon, lat

Requested coordinate vectors in degrees, without interpolation.

year_present, year_future

Nonempty vectors of calibration/evaluation years.

season_start_md, season_end_md

Inclusive month/day pairs on a 365-day reference calendar; wrapped intervals include both ends of each selected year.

strict_time_checks

Whether to enforce the legacy daily mapping assumptions.

season_selection_mode

Auto, exact_month_day, or fractional.

time_decode_mode

Auto, helpers_cf, or empirical date-decoding backend.

requested_year_policy

Warn or stop for unavailable/incomplete requested years under the legacy mapping. Warn is retained from production.

read_data

Logical; FALSE inspects metadata and creates plans without reading climate-variable cubes (coordinate/time axes are still read).

Value

List with optional data_present/data_future cubes, selected file indices and date keys, per-record year/slot metadata, diagnostics, year_table and a reusable block-reading plan. Data arrays are lon x lat x selected time. Known supported calendars use independent CF date keys; Julian/unknown fallback identities are explicitly labelled unverified year/slot strings.
