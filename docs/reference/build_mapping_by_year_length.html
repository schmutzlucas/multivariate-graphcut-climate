build_mapping_by_year_lengthR Documentation

Tabulate the fractional seasonal mapping for distinct year lengths

Description

Tabulate the fractional seasonal mapping for distinct year lengths

Usage

build_mapping_by_year_length(
  year_lengths,
  start_ref_doy,
  end_ref_doy,
  wraps_year_end
)

Arguments

year_lengths

Nonempty vector of positive integer model/empirical year lengths.

start_ref_doy

Inclusive start day on the 365-day reference calendar.

end_ref_doy

Inclusive end day on that reference calendar.

wraps_year_end

Whether selection includes both ends of each year.

Value

Data frame with one row per sorted unique year length and columns year_length, start_mod, end_mod and wraps_window; NULL for empty input.

Examples

build_mapping_by_year_length(c(360,365,366),1,365,FALSE)
