read_dimension_valuesR Documentation

Read a rectilinear NetCDF coordinate vector

Description

Read a rectilinear NetCDF coordinate vector

Usage

read_dimension_values(nc_obj, dim_name)

Arguments

nc_obj

Open ncdf4 handle, not closed by this function.

dim_name

Coordinate dimension name.

Value

Numeric coordinates, preferring cached dimension values to a variable. Raises an error if neither representation is available.
