match_values_with_toleranceR Documentation

Match coordinates exactly or by one unambiguous nearby value

Description

Match coordinates exactly or by one unambiguous nearby value

Usage

match_values_with_tolerance(requested, available, tolerance = 1e-06)

Arguments

requested

Numeric coordinate vector in desired order.

available

Numeric coordinates on the file axis.

tolerance

Absolute tolerance, in coordinate units, for fallback matching.

Value

Integer indices into available. Unmatched or ambiguous nonexact requests remain NA; exact matching uses R's first-match convention.

Examples

stopifnot(match_values_with_tolerance(1+1e-8, 1:3) == 1L)
