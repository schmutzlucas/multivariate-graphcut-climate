decode_time_components_for_exact_selectionR Documentation

Try to obtain year/month/day vectors for exact seasonal selection

Description

Try to obtain year/month/day vectors for exact seasonal selection

Usage

decode_time_components_for_exact_selection(
  nc_obj,
  time_dim_name,
  time_values,
  time_units,
  calendar,
  time_decode_mode
)

Arguments

nc_obj

Open NetCDF handle, not closed here.

time_dim_name

Time dimension supplied to optional CF helpers.

time_values

Numeric offsets for Gregorian fallback decoding.

time_units

CF time units with UTC origin.

calendar

Canonical calendar name.

time_decode_mode

Auto/helpers_cf/empirical; empirical skips optional helpers.

Value

List with ok, decoded year, month, day, source, and error_message. Non-Gregorian helper failure returns ok=FALSE; this routine does not invent Gregorian model dates.
