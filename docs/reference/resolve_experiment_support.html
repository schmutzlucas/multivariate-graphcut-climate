resolve_experiment_supportR Documentation

Require the configured support and verify corrected-data readiness/provenance

Description

Require the configured support and verify corrected-data readiness/provenance

Usage

resolve_experiment_support(mode = c("era5", "pme"))

Arguments

mode

ERA5 or PME support profile.

Value

Support path. With an active registry, requires the readiness receipt, unchanged registry/support SHA-256 and exact support model/year scope. Without a registry, only requires the archived support file to exist. Does not itself freshly hash climate inputs or approve scientific/source-version qualifications.
