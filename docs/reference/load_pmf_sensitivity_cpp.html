load_pmf_sensitivity_cppR Documentation

Load the histogram-sensitivity native routines for the current process/source

Description

Load the histogram-sensitivity native routines for the current process/source

Usage

load_pmf_sensitivity_cpp(
  cpp_file = "src/bin_sensitivity.cpp",
  cache_dir = file.path(tempdir(), "MVGraphCutRcppCache"),
  force_load = FALSE
)

Arguments

cpp_file

Path to the Rcpp histogram/count-distance implementation.

cache_dir

Rcpp build-cache directory; created when needed.

force_load

Whether to reload even when source identity and functions match.

Value

TRUE invisibly after native functions are available. Reuse requires matching canonical path/SHA-256 and process ID, not merely a global loaded flag. Multisession workers load their own DLL. Compilation requires Rcpp/toolchain.
