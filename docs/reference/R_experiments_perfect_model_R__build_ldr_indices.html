build_ldr_indicesR Documentation

Select tie-inclusive reference LDR bins independently at every grid cell

Description

Select tie-inclusive reference LDR bins independently at every grid cell

Usage

build_ldr_indices(pdf_ref, tau, lon_size, lat_size)

Arguments

pdf_ref

Valid normalised reference PMFs [lon,lat,bins] on the common support.

tau

Nominal ell_LDR mass threshold, passed to select_ldr_indices().

lon_size, lat_size

Spatial sizes matching the reference array.

Value

Nested list indexed longitude then latitude of one-based selected bin indices. Includes zero-probability bins and all cutoff ties. Uses reference probabilities only; no selected-mass renormalisation is performed.
