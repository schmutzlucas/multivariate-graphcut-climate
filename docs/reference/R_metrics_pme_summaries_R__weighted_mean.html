weighted_meanR Documentation

Compute a finite-pair weighted mean for a spatial PME score

Description

Compute a finite-pair weighted mean for a spatial PME score

Usage

weighted_mean(x, w)

Arguments

x, w

Numeric value/weight vectors of identical length.

Value

Weighted arithmetic mean over finite pairs with nonnegative weights; NA_real_ if no positive valid total weight remains. Negative/nonfinite weights are omitted, not converted to positive weights. Does not weight references.

Examples

stopifnot(weighted_mean(c(1,3),c(1,1)) == 2)
