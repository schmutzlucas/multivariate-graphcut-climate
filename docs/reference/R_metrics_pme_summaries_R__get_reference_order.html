get_reference_orderR Documentation

Require the complete held-out PME reference set for both methods

Description

Require the complete held-out PME reference set for both methods

Usage

get_reference_order(
  results,
  period_id,
  lambda_key,
  tau_key = NULL,
  metric_type
)

Arguments

results

Compact PME result list, including meta$model_names and method maps.

period_id

One named evaluation-period identifier.

lambda_key

Character GC smoothness key, usually "0.125".

tau_key

Character LDR threshold key, e.g. "0.01"; ignored for full Hellinger.

metric_type

Exactly full or partial (the internal identifier for LDR).

Value

Character vector in metadata model order. Missing, extra or duplicate references on either method raise an error instead of reducing the sample. Publication entry points separately require the configured set of 15 models.
