weighted_mean_valueR Documentation

Compute a finite-cell area-weighted mean

Description

Compute a finite-cell area-weighted mean

Usage

weighted_mean_value(field, weights, transform = identity)

Arguments

field, weights

Numeric field and nonnegative weights with identical shape.

transform

Elementwise function applied before selecting finite values.

Value

Scalar weighted mean or NA_real_ if no positive valid weight remains.
