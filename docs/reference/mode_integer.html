mode_integerR Documentation

Return the most frequent finite integer in a vector

Description

Return the most frequent finite integer in a vector

Usage

mode_integer(x)

Arguments

x

Numeric values, converted to integers before counting.

Value

Scalar integer mode, smallest value on a frequency tie, or NA for no finite observations. Used for legacy empirical year-length diagnostics.

Examples

stopifnot(mode_integer(c(365L,366L)) == 365L)
