compute_cube_min_maxR Documentation

Reduce a climate cube to local histogram-support extrema

Description

Reduce a climate cube to local histogram-support extrema

Usage

compute_cube_min_max(cube, variable)

Arguments

cube

Numeric lon x lat x time array in prepared physical units.

variable

Variable identifier. pr is transformed with log1p before extrema; tas and psl remain unchanged. Finite negative pr is corrected before log1p.

Value

List with lon x lat min/max matrices, omitting missing samples; nonfinite extrema become NA. This is not the strict corrected-input approval gate: infinities are invalid; missing observations are omitted. Cells with no valid observations retain NA bounds rather than an invented support.
