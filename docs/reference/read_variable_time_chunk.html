read_variable_time_chunkR Documentation

Read one contiguous time slab and requested rectilinear spatial positions

Description

Read one contiguous time slab and requested rectilinear spatial positions

Usage

read_variable_time_chunk(
  nc_obj,
  variable,
  dimension_info,
  lon_indices,
  lat_indices,
  time_start,
  time_count,
  report_qc = FALSE
)

Arguments

nc_obj

Open NetCDF handle, owned and closed by the caller.

variable

Three-dimensional variable name.

dimension_info

Original axis names, positions and sizes from get_variable_dimension_info().

lon_indices, lat_indices

Nonempty integer positions in the original file axes.

time_start

One-based first record of a contiguous time interval.

time_count

Positive integer number of time records.

report_qc

Whether to return list(data, qc) with raw precipitation statistics alongside corrected data; FALSE retains the ordinary array API.

Value

Lon x lat x time array, retaining singleton axes and requested spatial order, or list(data, qc) when requested. Finite negative pr is corrected immediately after reading; statistics describe only the selected cells. Reads a bounding spatial rectangle; no regridding or unit conversion.
