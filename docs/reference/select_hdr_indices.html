select_hdr_indicesR Documentation

Select a tie-inclusive high-density region

Description

Sort reference-bin probabilities from largest to smallest and retain every bin at least as probable as the first cutoff reaching mass 1 - tau.

Usage

select_hdr_indices(pdf_vector, tau = 0.1)

Arguments

pdf_vector

Numeric vector of reference-bin masses. Positive total mass is normalised internally; nonfinite and negative entries are treated as zero for legacy compatibility. Use validate_pmf() for strict validation.

tau

Scalar in [0, 1); nominal mass outside the HDR.

Details

Boundary ties are all included; the attained mass may exceed 1 - tau.

Value

Sorted one-based integer bin indices, or integer(0) for zero total mass.

Examples

select_hdr_indices(c(0, 0.1, 0.9), tau = 0.1)
