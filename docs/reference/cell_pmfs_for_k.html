cell_pmfs_for_kR Documentation

Construct one cell's odd/even trivariate PMFs at explicit resolutions

Description

Construct one cell's odd/even trivariate PMFs at explicit resolutions

Usage

cell_pmfs_for_k(pr, tas, psl, range_3d, split_masks, k_values)

Arguments

pr, tas, psl

Aligned numeric calibration samples; pr is already log transformed.

range_3d

Three x two common-support matrix in pr/tas/psl order.

split_masks

List of logical sample masks, normally odd and even years.

k_values

Positive integer per-variable resolutions to evaluate.

Value

Named resolution list, each containing split PMF vectors of length k^3. Empty complete-case splits retain NULL slots rather than deleting/shifting list entries. Uses the same equal-width floating-edge convention as production.
