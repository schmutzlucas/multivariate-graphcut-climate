Description

Require an explicitly selected external production result file

Usage

production_result_file(variable, description)

Arguments

variable

Environment-variable name holding the path.

description

Human-readable description included in a missing-file error.

Value

Existing path as a character string. Does not scan directories, choose a newest file, load a workspace, or verify its scientific/input identity.
