compute_k_sensitivity_blockR Documentation

Compute odd/even candidate-ranking stability for one latitude block

Description

Compute odd/even candidate-ranking stability for one latitude block

Usage

compute_k_sensitivity_block(
  lat_positions,
  plans,
  model_names,
  reference_name,
  variables,
  range_var,
  k_values,
  verbose = FALSE
)

Arguments

lat_positions

Positions of the block in the requested latitude vector.

plans

Matched model read plans from prepare_k_sensitivity_plans().

model_names

Distinct model identifiers including the reference.

reference_name

Model treated as reference, excluded from ranked candidates.

variables

Ordered pr/tas/psl identifiers.

range_var

Common full-grid support array [lon,lat,3,2].

k_values

Integer per-variable histogram resolutions.

verbose

Whether to print block progress.

Value

List lat_positions, rho, n_models_valid and elapsed_seconds. rho and counts are lon x local-lat x resolution arrays. Spearman correlation requires at least three finite candidate pairs and nonconstant ranks in both splits; otherwise rho is NA. Streams models, retaining only Hellinger scores, not all PMFs. Does not run future periods, graph cut, LDR or tune production k=8.
