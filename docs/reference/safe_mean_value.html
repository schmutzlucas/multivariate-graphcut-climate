safe_mean_valueR Documentation

Average observed values while retaining an explicit all-missing result

Description

Average observed values while retaining an explicit all-missing result

Usage

safe_mean_value(x)

Arguments

x

Numeric observations; NA and NaN are omitted, not infinite values.

Value

Scalar arithmetic mean, or NA_real_ for empty/all-missing input. Precipitation callers back-transform log values before invoking this helper.

Examples

stopifnot(is.na(safe_mean_value(c(NA_real_,NA_real_))))
