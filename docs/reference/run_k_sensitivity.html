run_k_sensitivityR Documentation

Run calibration-only split-sample model-rank stability across histogram sizes

Description

Uses odd/even calibration years and the same fixed local physical support at each k. Does not choose a new production discretisation, run graph cut or use future-period/reference-specific supports. Exact scientific input/code identity namespaces checkpoints; ordinary R comments/formatting do not invalidate them. Legacy directory identity uses file stats/plans, not full payload hashes; use the prepared-run launcher for fresh checksums before scientific reruns.

Usage

run_k_sensitivity(
  model_names,
  reference_name,
  variables,
  data_dir,
  years,
  lon,
  lat,
  range_var,
  k_values = 4:12,
  workers = 1L,
  latitude_block_size = 2L,
  strict_time_checks = TRUE,
  season_selection_mode = "auto",
  time_decode_mode = "auto",
  requested_year_policy = "warn",
  verbose = TRUE,
  checkpoint_dir = NULL
)

Arguments

model_names

Distinct model identifiers: one reference and at least three candidates.

reference_name

Single model identifier excluded from candidate ranks.

variables

Exactly c("pr","tas","psl").

data_dir

Prepared daily NetCDF root unless registry resolution is active.

years

Integer calibration years containing odd and even years.

lon, lat

Nonempty unique finite requested coordinates; latitudes in [-90,90].

range_var

Finite strictly increasing bounds [lon,lat,3,2], with pr transformed.

k_values

Integer bins per variable, sorted/deduplicated; default 4 through 12.

workers

Positive integer worker count; restores the prior future plan on exit.

latitude_block_size

Positive integer requested latitude positions per task.

strict_time_checks

Whether to enforce legacy daily-time assumptions.

season_selection_mode

Auto, exact_month_day, or fractional full-year selection.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for unavailable/incomplete years.

verbose

Whether to print metadata/block progress.

checkpoint_dir

Optional cache root. Namespaces exact identities, atomically installs new blocks, and rejects malformed/incompatible existing records.

Value

List summary (area/unweighted mean rho and valid coverage), rho and n_models_valid arrays [lon,lat,k], and metadata including input/code cache identity and per-block reuse/timings. Correlations average over valid cells; this measures rank stability, not GC relative improvement over D-MMM.
