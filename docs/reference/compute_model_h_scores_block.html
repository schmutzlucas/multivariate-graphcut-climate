compute_model_h_scores_blockR Documentation

Evaluate one candidate's split Hellinger scores through the R reference path

Description

Evaluate one candidate's split Hellinger scores through the R reference path

Usage

compute_model_h_scores_block(
  raw,
  model_plan,
  reference_pmfs,
  range_var,
  lat_positions,
  k_values
)

Arguments

raw

Named pr/tas/psl calibration cubes with already transformed pr.

model_plan

Candidate selected-year odd/even masks.

reference_pmfs

Reference list arrays from compute_reference_pmfs_block().

range_var

Common full-grid support array [lon,lat,3,2].

lat_positions

Full-grid positions for this latitude block.

k_values

Integer per-variable resolutions in desired output order.

Value

Numeric array lon x local-lat x resolution x two splits. Empty sample comparisons are NA. This is a verification helper, not graph-cut optimisation.
