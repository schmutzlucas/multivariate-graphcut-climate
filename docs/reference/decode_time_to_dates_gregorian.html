decode_time_to_dates_gregorianR Documentation

Decode a Gregorian time coordinate to UTC dates

Description

This routine uses R's proleptic Gregorian/UTC arithmetic. It is appropriate for the modern Article 1 Gregorian dates, not 360-day or no-leap calendars or historical mixed-calendar reform transitions.

Usage

decode_time_to_dates_gregorian(time_values, time_units)

Arguments

time_values

Numeric offsets in the declared time units.

time_units

One days/hours/seconds-since units string with UTC origin.

Value

R Date vector; records are assigned to their UTC calendar day.

Examples

stopifnot(all(as.character(decode_time_to_dates_gregorian(c(0,24),
  "hours since 2000-01-01")) == c("2000-01-01","2000-01-02")))
