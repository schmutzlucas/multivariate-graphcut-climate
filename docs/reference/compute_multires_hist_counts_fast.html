compute_multires_hist_counts_fastR Documentation

Build the Article 1 univariate, bivariate and trivariate counts together

Description

Build the Article 1 univariate, bivariate and trivariate counts together

Usage

compute_multires_hist_counts_fast(
  pr,
  tas,
  psl,
  range_3d,
  nbins3d = 8L,
  nbins2d = 16L,
  nbins1d = 32L,
  profile = FALSE
)

Arguments

pr, tas, psl

Equally sized numeric observation vectors. Precipitation must already have the production log(1 + precipitation) transform applied.

range_3d

A 3 x 2 matrix of transformed/physical bounds ordered pr,tas,psl.

nbins3d, nbins2d, nbins1d

Per-axis resolutions for three-, two-, and one-dimensional histograms. Article 1 fixes these to 8, 16 and 32.

profile

Logical; append indexing/tabulation timings in seconds.

Details

Nested resolutions reuse finest-grid indices. Non-nested settings compute their grids separately. Missing values are excluded per diagnostic, so marginal sample counts can differ when raw variables contain missing data.

Value

List pdf3 (joint counts), pdf2 (pr_tas, pr_psl, tas_psl count vectors), and pdf1 (pr, tas, psl counts), with optional timing. The pdf names are legacy: values are counts until the calling PMF builder normalises each histogram.

Examples

x <- c(0.1, 0.5, 0.9)
counts <- compute_multires_hist_counts_fast(x, x, x, cbind(rep(0, 3), rep(1, 3)))
sum(counts$pdf3)
