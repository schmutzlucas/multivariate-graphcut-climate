plot_cached_reference_densityR Documentation

Replay a reference-faceted PME density figure from its numeric recipe

Description

Replay a reference-faceted PME density figure from its numeric recipe

Usage

plot_cached_reference_density(recipe)

Arguments

recipe

Plot-recipe list with coordinates (x,y,method,group,reference), annotations (x_value,method,statistic,reference) and labels (title,subtitle). MMM is the internal D-MMM method identifier; GC-0.125 is the other method.

Value

ggplot object using five facet columns, original curve coordinates and weighted-mean/median markers. The visible legend says D-MMM. No recomputation of densities or summaries and no output-file or graphics-device side effects.
