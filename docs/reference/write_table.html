write_tableR Documentation

Write a manuscript-ready booktabs table from already formatted LaTeX fragments

Description

Write a manuscript-ready booktabs table from already formatted LaTeX fragments

Usage

write_table(filename, label, caption, header, rows, columns)

Arguments

filename

Output filename below caller-environment out; existing generated files follow writeLines() overwrite behaviour.

label, caption

LaTeX label and caption text, supplied without escaping.

header

Character header row without the terminating line break.

rows

Character vector of body rows without terminating line breaks.

columns

LaTeX tabular column specification, e.g. lrrr.

Value

NULL invisibly after writing a complete table environment. Caller must provide valid LaTeX and booktabs in the manuscript; no document compilation.
