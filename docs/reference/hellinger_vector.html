hellinger_vectorR Documentation

Compute ordinary Hellinger distance for two valid PMF vectors

Description

Compute ordinary Hellinger distance for two valid PMF vectors

Usage

hellinger_vector(pdf_ref, pdf_model)

Arguments

pdf_ref, pdf_model

Numeric normalised PMFs on identical ordered bins.

Value

Scalar Hellinger distance in [0,1]. Invalid masses raise an error; they are never clipped or replaced with zeros.
