write_period_resultR Documentation

Save a compact PME period result with explicit metadata

Description

Save a compact PME period result with explicit metadata

Usage

write_period_result(
  period_result,
  period_row,
  period_output_dir,
  run_stamp,
  meta_base
)

Arguments

period_result

Nested score/solver/checkpoint containers for one period.

period_row

One-row target period descriptor.

period_output_dir

Destination directory, created recursively if absent.

run_stamp

Run identifier used in the filename; select a new run directory to avoid normal saveRDS overwrite behaviour.

meta_base

Shared scientific/input metadata.

Value

Written compact RDS path. Adds save time and completed-reference list; does not independently certify that all required references have completed.
