summarise_meansR Documentation

Summarise method-wise area-weighted means of stacked PME density samples

Description

Summarise method-wise area-weighted means of stacked PME density samples

Usage

summarise_means(df_period)

Arguments

df_period

Data frame with method, value and weight columns.

Value

Tibble with one row per method and weighted_mean, computed over finite value/weight pairs. Requires dplyr; does not compute reference-wise improvements.
