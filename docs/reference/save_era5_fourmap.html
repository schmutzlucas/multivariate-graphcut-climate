save_era5_fourmapR Documentation

Save and verify accepted ERA5 map layouts

Description

Save and verify accepted ERA5 map layouts

Usage

save_era5_fourmap(plot, base, cache_path)

Arguments

plot

Gtable returned by the accepted four-map builder, with era5_layout metadata.

base

Output filename stem without extension; parent directory must exist.

cache_path

Existing compact RDS input whose bytes must remain unchanged.

Value

Audit list invisibly; writes PDF, PNG and verification JSON at base, overwriting prior files. Requires Cairo and ragg; verifies cache hash remains unchanged.
