compute_histND_equal_width_fastR Documentation

Count an equal-width histogram using vectorised indices

Description

Count an equal-width histogram using vectorised indices

Usage

compute_histND_equal_width_fast(data, range_var, nbins)

Arguments

data

Numeric observations x variables matrix or matrix-coercible data.

range_var

Variables x 2 matrix of finite minimum/maximum bounds.

nbins

Positive integer bins per axis, not total multivariate states.

Details

Applies equal_width_bin_index() separately to each variable and excludes rows with missing bin assignments. One-observation and empty inputs retain their correct multivariate dimensionality. See floating-edge semantics in equal_width_bin_index(); this function does not normalise counts.

Value

Integer count vector of length nbins^ncol(data), in column-major bin order.

Examples

compute_histND_equal_width_fast(matrix(c(0.2, 0.8), 1), cbind(c(0, 0), c(1, 1)), 8)
