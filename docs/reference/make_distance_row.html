make_distance_rowR Documentation

Create one spatial distance-summary row with archived column identities

Description

Create one spatial distance-summary row with archived column identities

Usage

make_distance_row(
  method,
  dimension,
  variable_set,
  metric_type,
  tau,
  field,
  weights
)

Arguments

method

Method identifier; MMM internally denotes D-MMM.

dimension, variable_set

Dimension and variable-set labels.

metric_type

Archived metric identifier, e.g. full_H or partial_LDR_H.

tau

LDR threshold; NULL for ordinary Hellinger.

field, weights

Numeric score map and nonnegative weights of identical shape.

Value

One-row data frame of identifiers, H units and summarize_map() statistics.
