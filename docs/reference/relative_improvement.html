relative_improvementR Documentation

Compute paired relative improvement over D-MMM

Description

Compute paired relative improvement over D-MMM

Usage

relative_improvement(baseline, candidate)

Arguments

baseline

Finite positive D-MMM scores, one per comparison.

candidate

Finite GC scores in the same order and of the same length.

Details

Positive values favour GC. Reference-wise paper summaries apply this after obtaining each held-out reference's area-weighted score; they do not average grid-cell percentage ratios or weight references by model size.

Value

Numeric percentages 100 * (baseline - candidate) / baseline.

Examples

relative_improvement(c(4, 2), c(3, 1.5))
