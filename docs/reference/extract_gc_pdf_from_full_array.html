extract_gc_pdf_from_full_arrayR Documentation

Extract the spatially selected candidate PMF from a reference-first array

Description

Extract the spatially selected candidate PMF from a reference-first array

Usage

extract_gc_pdf_from_full_array(pdf_full, gc_labels)

Arguments

pdf_full

Numeric array longitude x latitude x bins x models, with reference at index 1 and at least one candidate afterwards.

gc_labels

Finite integer longitude x latitude matrix indexing candidates from 1, so candidate label k selects full model index k+1.

Value

Longitude x latitude x bins array, retaining singleton spatial axes. Invalid shapes, missing labels or labels outside candidate range error.
