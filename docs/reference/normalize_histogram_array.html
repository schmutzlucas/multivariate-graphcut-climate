normalize_histogram_arrayR Documentation

Normalise finite nonnegative histogram counts separately at every grid cell

Description

Normalise finite nonnegative histogram counts separately at every grid cell

Usage

normalize_histogram_array(arr)

Arguments

arr

Numeric longitude x latitude x bin count array; axes must be nonempty.

Value

Array of identical shape with each nonempty cell summing to one. All-zero cells remain all zero under the legacy convention: they are not valid PMFs, and native graph-cut validation rejects them. Invalid input counts raise errors rather than being silently replaced with zeros.

Examples

normalize_histogram_array(array(c(1,3),c(1,1,2)))
