Description

Convert a seasonal boundary to its one-based reference day

Usage

month_day_to_reference_doy(md)

Arguments

md

Integer month/day pair valid in a 365-day year.

Value

Integer day of year in 1 through 365, using year 2001.

Examples

stopifnot(month_day_to_reference_doy(c(3, 1)) == 60L)
