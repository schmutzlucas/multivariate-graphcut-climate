validate_map_dimR Documentation

Require a PME map's exact spatial array dimensions

Description

Require a PME map's exact spatial array dimensions

Usage

validate_map_dim(map_obj, expected_dim, label)

Arguments

map_obj

Matrix/array to inspect.

expected_dim

Expected dimension vector; no transposition or reshaping is guessed.

label

Scientific map identity included in errors.

Value

NULL invisibly on success; errors on wrong rank/shape. Does not itself certify finite values, successful optimisation, units or statistical identity.
