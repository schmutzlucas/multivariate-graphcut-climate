estimate_selected_cube_gbR Documentation

Estimate the payload size of one dense spatial-time cube

Description

Estimate the payload size of one dense spatial-time cube

Usage

estimate_selected_cube_gb(nlon, nlat, ntime, bytes_per_value = 8)

Arguments

nlon, nlat, ntime

Nonnegative dimensions of the requested cube.

bytes_per_value

Storage bytes per numeric value, default eight for R doubles.

Value

Numeric size in GiB (2^30 bytes), despite the historical gb suffix. Does not include copies, object overhead, decompression or NetCDF caches.

Examples

stopifnot(estimate_selected_cube_gb(1024,1024,128) == 1)
