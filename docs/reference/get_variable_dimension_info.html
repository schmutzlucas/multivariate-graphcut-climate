get_variable_dimension_infoR Documentation

Describe the axes of a three-dimensional rectilinear climate variable

Description

Describe the axes of a three-dimensional rectilinear climate variable

Usage

get_variable_dimension_info(nc_obj, variable, time_dim_name)

Arguments

nc_obj

Open NetCDF handle, not closed here.

variable

NetCDF variable name, required to have exactly three axes.

time_dim_name

Name of that variable's time axis.

Value

List with original dimension names/sizes, longitude/latitude/time positions and names. Accepted spatial aliases are lon/longitude/x and lat/latitude/y.
