validate_k_sensitivity_blockR Documentation

Validate a freshly computed or cached histogram-resolution block

Description

Validate a freshly computed or cached histogram-resolution block

Usage

validate_k_sensitivity_block(value, dimensions, lat_positions, candidate_count)

Arguments

value

Block list with rho, n_models_valid, lat_positions and elapsed_seconds.

dimensions

Expected longitude x local-latitude x resolution dimensions.

lat_positions

Exact ordered full-grid latitude positions.

candidate_count

Total distinct ranked candidates, excluding the reference.

Value

TRUE invisibly or an error. Undefined correlations may be NA, but not NaN/Inf; finite correlations must lie in [-1,1] and have at least three valid candidates. Counts must be integer-valued and within the candidate population. This is structural/physical validation, not a cryptographic payload checksum.
