infer_unknown_year_lengthR Documentation

Estimate a fixed year length for an unsupported calendar

Description

This legacy fallback divides the number of records by the inclusive filename year span and rounds to an integer. It cannot establish that individual dates or complete years are actually present; use the independent CF audit for that.

Usage

infer_unknown_year_length(parsed_dates, n_time)

Arguments

parsed_dates

List with integer start_year and end_year.

n_time

Number of time records in the file.

Value

Estimated year length, restricted to 200 through 500 days.

Examples

infer_unknown_year_length(list(start_year=2000L, end_year=2001L), 720L)
