Count complete multivariate samples with an explicit empty-sample result

Description

Count complete multivariate samples with an explicit empty-sample result

Usage

safe_hist_counts(data_matrix, range_matrix, nbins, compute_hist_nd_fun)

Arguments

data_matrix

Observation x variable matrix; vectors become one-column matrices.

range_matrix

Variable x two matrix of lower/upper common histogram bounds.

nbins

Positive integer number of bins per variable.

compute_hist_nd_fun

Histogram callback accepting data, range_var and nbins.

Value

Flattened count vector of length nbins to the number of variables. Rows with NA/NaN are removed; an entirely empty sample returns all zero counts. Infinite values are not removed by complete.cases and follow the callback's boundary policy. Corrected production inputs are independently checked finite.

Examples

safe_hist_counts(matrix(c(0.2,NA,0.8),ncol=1),matrix(c(0,1),nrow=1),8,compute_histND)
