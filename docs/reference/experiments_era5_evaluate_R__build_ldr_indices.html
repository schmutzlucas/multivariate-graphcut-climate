Select reference-defined LDR bins for every grid cell

Description

Select reference-defined LDR bins for every grid cell

Usage

build_ldr_indices(pdf_ref, tau)

Arguments

pdf_ref

Reference PMF array indexed longitude x latitude x bins.

tau

LDR cumulative-mass threshold in (0,1), called ell_LDR in the paper.

Value

Nested longitude/latitude lists following select_ldr_indices(), including zero-reference bins and its complete cutoff-tie rule.
