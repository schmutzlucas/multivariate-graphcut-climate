make_comparison_rowR Documentation

Compare D-MMM and GC on the same finite spatial area

Description

Compare D-MMM and GC on the same finite spatial area

Usage

make_comparison_row(
  metric_family,
  dimension,
  variable_set,
  metric_type,
  tau,
  mmm_field,
  gc_field,
  weights,
  local_error_already_absolute = FALSE
)

Arguments

metric_family, dimension, variable_set, metric_type

Archived identity labels.

tau

LDR threshold or NULL for ordinary Hellinger.

mmm_field, gc_field

Numeric error/score fields of identical shape.

weights

Nonnegative weights of that shape.

local_error_already_absolute

Retained compatibility argument. Fraction improved always compares absolute values, which also applies to nonnegative H.

Value

One-row data frame with paired means, GC-minus-D-MMM delta, relative improvement (NA for a nonpositive/missing baseline) and improved-area fraction. Both means use the intersection of finite fields with positive finite weights.
