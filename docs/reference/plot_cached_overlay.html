plot_cached_overlayR Documentation

Replay a five-period PME density overlay from archived curve coordinates

Description

Replay a five-period PME density overlay from archived curve coordinates

Usage

plot_cached_overlay(
  recipe,
  metric_type = "full",
  tau_key = NULL,
  inset_layout = c("standard", "appendix_enlarged")
)

Arguments

recipe

Numeric plot-recipe list with coordinates (x,y,group,colour), five-row annotations (period_label,mmm,gc,mmm_color,gc_color,y) and a finite positive y_limit. No ggplot object or full experiment workspace is needed.

metric_type

Either full for ordinary Hellinger or partial for LDR.

tau_key

Numeric-character ell_LDR threshold in (0,1) for partial; NULL for full. Formatting is preserved in the plotmath table heading.

inset_layout

Standard main-text or enlarged appendix inset typography.

Value

ggplot object with the original curves, table, colours and layout. Does not re-estimate densities, average references, save files or run graph cut.
