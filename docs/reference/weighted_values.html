weighted_valuesR Documentation

Select finite positive-weight samples without recycling mismatched fields

Description

Select finite positive-weight samples without recycling mismatched fields

Usage

weighted_values(field, weights, transform = identity)

Arguments

field

Numeric field, usually a longitude x latitude matrix.

weights

Numeric weights with exactly the same length and dimensions. Nonfinite or zero weights are excluded; finite negative weights are invalid.

transform

Function returning one numeric transformed value per input cell.

Value

List with valid transformed values, their weights and a logical valid mask in column-major order. Missing field cells are excluded with their weights.
