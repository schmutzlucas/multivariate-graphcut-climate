combine_two_rangesR Documentation

Combine two legacy support cubes using local minima and maxima

Description

Combine two legacy support cubes using local minima and maxima

Usage

combine_two_ranges(range_a, range_b)

Arguments

range_a, range_b

Identically shaped [lon,lat,variable,2] support arrays.

Value

Cube of the same shape/dimnames, taking the available endpoint when only one is NA. Errors if combined min exceeds max; does not approve remaining missing/zero-width bounds. Retained for archived workflows, not used to build separate held-out supports in the current common-support PME.
