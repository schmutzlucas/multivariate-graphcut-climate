resolve_time_units_scale_daysR Documentation

Convert supported CF time units to a scale in days

Description

Convert supported CF time units to a scale in days

Usage

resolve_time_units_scale_days(time_units)

Arguments

time_units

Character units attribute of the form days/hours/seconds since origin.

Value

Scalar multiplier (1, 1/24, or 1/86400); unsupported units raise an error.

Examples

stopifnot(resolve_time_units_scale_days("hours since 1950-01-01") == 1/24)
