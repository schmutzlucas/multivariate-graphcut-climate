equal_width_bin_indexR Documentation

Assign equal-width bins with explicit floating-edge handling

Description

Assign equal-width bins with explicit floating-edge handling

Usage

equal_width_bin_index(x, xmin, xmax, nbins, zero_based = TRUE)

Arguments

x

Numeric observations; NA/NaN produce missing indices. Infinite and out-of-range observations saturate into the outermost bins.

xmin, xmax

Finite scalar support limits with xmax strictly larger.

nbins

Positive integer number of bins along this one variable.

zero_based

Logical; return 0 through nbins - 1 rather than R's 1-based bins.

Details

Values within eight scaled machine epsilons of an internal edge are snapped to that edge before flooring. This stabilises nested-bin derivation but is not bit-identical to findInterval for every value infinitesimally below an edge. Ordinary exact edges belong to the bin on their right; xmax belongs to the final bin. No physical support bounds are re-estimated here.

Value

Integer bin indices of length length(x), preserving missing entries.

Examples

equal_width_bin_index(c(0, 0.25, 0.5, 1), 0, 1, 4)
