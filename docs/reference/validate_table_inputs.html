validate_table_inputsR Documentation

Validate the archived numerical inputs required by Article 1 tables

Description

Validate the archived numerical inputs required by Article 1 tables

Usage

validate_table_inputs(era, pme, periods, expected_references)

Arguments

era

ERA5 long-statistics data frame, with unique scientific identities and finite numeric metric_value. Missing tau is allowed for ordinary metrics.

pme

Reference-score data frame with reference, period_id, metric, H_D_MMM, H_GC and relative_improvement_pct columns.

periods

Configured period data frame containing unique period_id values.

expected_references

Exact configured held-out reference set, normally 15 models.

Value

TRUE invisibly, or an error for invalid/duplicate data, inconsistent relative improvements or incomplete full-H/LDR-one-percent reference-period populations. No table is written and no numerical input is modified.
