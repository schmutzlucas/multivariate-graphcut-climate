era5_fill_scaleR Documentation

Construct the accepted diagnostic colour scale

Description

Construct the accepted diagnostic colour scale

Usage

era5_fill_scale(kind, limits)

Arguments

kind

Diagnostic kind: distributional or bias for layouts, hellinger or bias for scales.

limits

Numeric two-element colour limits in the diagnostic units.

Value

ggplot2 fill scale with supplied limits and squishing outside them; no values modified.
