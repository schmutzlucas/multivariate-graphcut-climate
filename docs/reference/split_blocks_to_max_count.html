split_blocks_to_max_countR Documentation

Split contiguous NetCDF blocks into bounded-size chunks

Description

Split contiguous NetCDF blocks into bounded-size chunks

Usage

split_blocks_to_max_count(blocks, max_count)

Arguments

blocks

Data frame with finite integer start >= 1 and count >= 0 columns.

max_count

Finite positive integer maximum records per output chunk.

Value

Data frame of start/count chunks, preserving input block order and coverage. Zero-count blocks are omitted; empty input returns a typed empty table.

Examples

split_blocks_to_max_count(data.frame(start=4L,count=8L),3L)
