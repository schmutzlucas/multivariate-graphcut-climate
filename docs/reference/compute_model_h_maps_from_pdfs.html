compute_model_h_maps_from_pdfsR Documentation

Evaluate every candidate model against reference-selected bins

Description

Evaluate every candidate model against reference-selected bins

Usage

compute_model_h_maps_from_pdfs(pdf_ref, pdf_models, selected_indices)

Arguments

pdf_ref

Valid reference PMF array longitude x latitude x bins.

pdf_models

Valid candidate array longitude x latitude x bins x models.

selected_indices

Nested longitude/latitude bin-index lists.

Value

Longitude x latitude x models score array, retaining missing scores and a singleton model dimension. Does not normalise restricted PMFs.
