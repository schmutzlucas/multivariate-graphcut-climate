validate_target_pmfsR Documentation

Validate target PMFs before handing their memory to native callbacks

Description

Validate target PMFs before handing their memory to native callbacks

Usage

validate_target_pmfs(pdf_models_future, tolerance = 1e-08)

Arguments

pdf_models_future

Numeric longitude x latitude x bins x models array.

tolerance

Absolute tolerance for each local PMF's total mass.

Details

Scans one latitude slab at a time to bound extra memory. Missing, negative and nonfinite masses are rejected before C++ square roots or graph optimisation can consume them. Valid PMFs are not modified or renormalised.

Value

TRUE invisibly; invalid masses or dimensions raise an R error.

Examples

validate_target_pmfs(array(0.5, c(3, 2, 2, 2)))
