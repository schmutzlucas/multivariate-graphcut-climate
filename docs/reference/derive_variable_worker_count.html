derive_variable_worker_countR Documentation

Limit support workers using the heuristic per-task memory estimate

Description

Limit support workers using the heuristic per-task memory estimate

Usage

derive_variable_worker_count(
  variable,
  slab_gb,
  requested_workers,
  memory_budget_gb
)

Arguments

variable

Variable name passed to the task-memory estimator.

slab_gb

Estimated raw cube/slab size per task in GiB; must be positive.

requested_workers

Positive integer upper limit from the resource configuration.

memory_budget_gb

Finite positive scheduling budget in GiB.

Value

Integer worker count between one and requested_workers. The minimum of one does not guarantee a task fits when its estimate exceeds the budget.
