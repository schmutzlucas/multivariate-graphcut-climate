extract_fractional_point_seriesR Documentation

Extract one location's raw seasonal series with calendar metadata

Description

Extract one location's raw seasonal series with calendar metadata

Usage

extract_fractional_point_series(
  nc_file,
  variable,
  lon_target,
  lat_target,
  year_span,
  season_start_md,
  season_end_md,
  strict_time_checks = TRUE,
  season_selection_mode = c("auto", "exact_month_day", "fractional"),
  time_decode_mode = c("auto", "helpers_cf", "empirical"),
  requested_year_policy = c("warn", "stop")
)

Arguments

nc_file

Path to a prepared daily NetCDF file.

variable

Variable name, in its prepared units without further conversion.

lon_target, lat_target

Scalar geographic coordinates matched without interpolation.

year_span

Requested years, sorted and deduplicated.

season_start_md, season_end_md

Inclusive non-leap reference month/day boundaries.

strict_time_checks

Whether to enforce legacy daily-mapping assumptions.

season_selection_mode

Auto, exact_month_day, or fractional selection.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for unavailable/incomplete years.

Value

Data frame with year, year_length, doy and value. Here doy is the active mapping's slot (possibly empirical rank), not necessarily true DOY. Decodable exact-selection dates additionally provide month and day columns.
