era5_colourbar_unitR Documentation

Select mean-bias colourbar units

Description

Select mean-bias colourbar units

Usage

era5_colourbar_unit(kind, row)

Arguments

kind

Diagnostic kind: distributional or bias for layouts, hellinger or bias for scales.

row

One-based diagnostic row (1 or 2).

Value

Kelvin or mm/day label, or NULL for distributional maps.
