weighted_quantileR Documentation

Compute a scalar weighted empirical quantile of finite samples

Description

Compute a scalar weighted empirical quantile of finite samples

Usage

weighted_quantile(x, w, prob = 0.5)

Arguments

x, w

Numeric values and corresponding nonnegative weights of identical length and shape. Nonfinite values/weights and zero weights are omitted.

prob

Scalar finite probability in [0,1], default median 0.5.

Value

First sorted positive-weight value reaching prob, or NA_real_ if no positive finite weight remains. No interpolation or sample correction.
