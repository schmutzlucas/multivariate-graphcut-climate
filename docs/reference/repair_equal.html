repair_equalR Documentation

Require exact preservation of existing decoded climate values

Description

Require exact preservation of existing decoded climate values

Usage

repair_equal(actual, expected, context)

Arguments

actual, expected

Numeric arrays to compare, with matching dimensions and NA pattern.

context

Diagnostic description included in failure messages.

Value

Number of expected values invisibly. Errors on shape/missing-pattern mismatch, non-missing nonfinite actual values, or any nonzero absolute difference. This is exact value comparison, not a configurable numerical tolerance.

Examples

repair_equal(array(c(1,NA),c(1,1,2)),array(c(1,NA),c(1,1,2)),"example")
