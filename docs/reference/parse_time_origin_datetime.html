parse_time_origin_datetimeR Documentation

Extract a UTC date-time origin from a CF units string

Description

Extract a UTC date-time origin from a CF units string

Usage

parse_time_origin_datetime(time_units)

Arguments

time_units

One units string containing since, an ISO date and optional time. UTC or Z suffixes are accepted; numeric zone offsets are not supported.

Value

Scalar UTC POSIXct; missing or unparseable origins raise an error.

Examples

parse_time_origin_datetime("hours since 1950-01-01T12:00:00Z")
