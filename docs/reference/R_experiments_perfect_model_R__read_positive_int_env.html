read_positive_int_envR Documentation

Read a positive-integer environment setting for PME orchestration

Description

Read a positive-integer environment setting for PME orchestration

Usage

read_positive_int_env(var_name, default_value)

Arguments

var_name

Environment-variable name.

default_value

Positive integer fallback when unset or invalid.

Value

Integer, warning and using the default for fractional/nonfinite/ nonpositive/out-of-range values. This helper does not choose scientific parameters.
