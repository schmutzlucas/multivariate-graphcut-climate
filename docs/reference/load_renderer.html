load_rendererR Documentation

Load only whitelisted renderer definitions from source text

Description

Load only whitelisted renderer definitions from source text

Usage

load_renderer(code, environment)

Arguments

code

Character vector of R source lines; no top-level figure commands are executed. Definitions allowed are the caller's definitions character vector.

environment

Environment in which to evaluate the selected assignments.

Value

NULL invisibly; modifies environment with the whitelisted constants and function definitions, allowing tile and raster renderers to share code.
