require_climate_dataR Documentation

Check whether the configured production data collection is discoverable

Description

Check whether the configured production data collection is discoverable

Usage

require_climate_data(config = article1_config())

Arguments

config

Configuration list with input_registry and data_root fields.

Value

Registry directory or data root invisibly. A registry is structurally checked; a directory-only root is checked for existence. This is not a payload checksum, coverage, unit, or complete-input validation. No computation starts.
