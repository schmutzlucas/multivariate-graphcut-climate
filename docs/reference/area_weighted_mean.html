area_weighted_meanR Documentation

Average a global field with cosine-latitude weights

Description

Average a global field with cosine-latitude weights

Usage

area_weighted_mean(field, lat)

Arguments

field

Numeric matrix indexed longitude x latitude, on equal-width longitude cells. Nonfinite field values are excluded with their weights.

lat

Latitude centres in degrees north, one per field column, in [-90, 90].

Details

Weights are proportional to cos(latitude), as used in Article 1. This is not a general irregular-grid cell-area calculator.

Value

Finite weighted mean, or NA_real_ if no positive valid weight remains.

Examples

area_weighted_mean(matrix(c(1, 1, 3, 3), 2), c(0, 60))
