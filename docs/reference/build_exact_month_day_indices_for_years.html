build_exact_month_day_indices_for_yearsR Documentation

Select inclusive seasonal dates from decoded month/day components

Description

Wrapped seasons include both ends of each selected year; no cross-year reassignment is made. Completeness diagnostics come from year_table; this routine checks missing years and empty selections, not every expected date.

Usage

build_exact_month_day_indices_for_years(
  year_table,
  timestep_year,
  timestep_slot,
  timestep_month,
  timestep_day,
  selected_years,
  season_start_md,
  season_end_md,
  requested_year_policy = c("warn", "stop")
)

Arguments

year_table

Year diagnostics from infer_time_structure_daily().

timestep_year

Decoded year for each file record.

timestep_slot

Parallel slot/rank vector used in diagnostics only.

timestep_month

Parallel decoded month vector.

timestep_day

Parallel decoded day vector.

selected_years

Requested years, sorted and deduplicated.

season_start_md

Inclusive start boundary on the 365-day reference calendar.

season_end_md

Inclusive end boundary on that calendar.

requested_year_policy

Warn or stop for missing years or empty selections.

Value

List with integer file indices and year_summary table; raises an error if the combined selection is empty.
