read_choice_envR Documentation

Read an enumerated environment setting for support construction

Description

Read an enumerated environment setting for support construction

Usage

read_choice_env(var_name, default_value, allowed)

Arguments

var_name

Environment-variable name.

default_value

Value to return when unset or empty; caller supplies a valid choice.

allowed

Character vector of exact accepted values; matching is case sensitive.

Value

Default or selected string; unrecognised nonempty settings raise an error.
