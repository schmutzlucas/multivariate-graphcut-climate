validate_month_dayR Documentation

Validate a seasonal boundary on the non-leap reference calendar

Description

Seasonal boundaries use a 365-day reference year, not a particular model calendar. February 29 is therefore not an admissible boundary. Whole-year extraction can nevertheless include leap days in the data.

Usage

validate_month_day(md, arg_name)

Arguments

md

Numeric length-two vector containing integer month and day.

arg_name

Argument label used in error messages.

Value

Integer vector c(month, day); invalid boundaries raise an error.

Examples

validate_month_day(c(12, 31), "season_end")
