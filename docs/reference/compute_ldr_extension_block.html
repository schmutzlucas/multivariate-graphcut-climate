compute_ldr_extension_blockR Documentation

Evaluate reference-defined LDR scores for all saved lambda label maps

Description

Evaluate reference-defined LDR scores for all saved lambda label maps

Usage

compute_ldr_extension_block(pmfs, labels, thresholds, models, lon_size)

Arguments

pmfs

Numeric array bins x cells x models of finite nonnegative PMFs normalised per cell/model on the single common PME support.

labels

Named lambda list of named reference matrices on this latitude block; labels index the ordered candidates obtained after excluding that reference.

thresholds

Named numeric ell_LDR values strictly in (0,1).

models

Ordered reference/model identifiers matching the PMF model axis.

lon_size

Positive integer number of longitude cells; cells must divide exactly.

Value

Named threshold list with MMM reference matrices and GC lambda/reference matrices. Uses equal-model means, all zero-reference/cutoff-tied bins and the non-renormalised Hellinger formula. No labels are optimised or modified.
