precipitation_qcR Documentation

Enforce nonnegative finite precipitation without modifying missing values

Description

Enforce nonnegative finite precipitation without modifying missing values

Usage

precipitation_qc(values)

Arguments

values

Numeric precipitation vector/array in already prepared units.

Value

Copy with every finite negative observation replaced by zero. Existing zeros/positives, dimensions, NA and NaN are preserved. Infinities are retained as invalid observations, not silently repaired; production validation rejects them. No unit conversion, file editing or logarithm is performed here.

Examples

stopifnot(identical(precipitation_qc(c(-1, 0, 2, NA_real_)), c(0, 0, 2, NA_real_)))
