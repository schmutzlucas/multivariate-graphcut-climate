make_bias_rowR Documentation

Summarise mean-field error against the reference

Description

Summarise mean-field error against the reference

Usage

make_bias_row(method, variable, method_field, ref_field, weights)

Arguments

method

Internal method identifier; MMM is the distributional baseline.

variable

Variable identifier pr, tas or psl.

method_field, ref_field

Numeric spatial means on an identical grid.

weights

Nonnegative weights of that grid shape.

Value

One-row data frame of signed/absolute bias, RMSE, absolute-error quantiles, spatial correlation and valid-area fraction. Historical units are K for tas and explicitly unqualified native units for pr/psl; no conversion.
