plot_weighted_density_by_referenceR Documentation

Estimate and plot Hellinger densities for each held-out reference

Description

Estimate and plot Hellinger densities for each held-out reference

Usage

plot_weighted_density_by_reference(
  df_metric,
  summary_table,
  metric_label,
  method_colors,
  period_label
)

Arguments

df_metric

Data frame with reference, method, value and weight columns; method uses the internal MMM/GC-0.125 identifiers. Values are scores in [0,1] and weights are cosine-latitude areas for each regular-grid cell.

summary_table

Data frame with reference, method, weighted_mean and weighted_median columns, computed from the same cells and weights.

metric_label

Scalar figure title identifying the diagnostic.

method_colors

Named colour vector for the internal method identifiers.

period_label

Target-period text included in the calibration/evaluation subtitle.

Value

ggplot object with boundary-corrected weighted KDEs (adjust 1, bounds [0,1]), five facet columns and supplied mean/median markers. No files written. Visible legend labels translate MMM to D-MMM; raw numerical inputs are retained.
