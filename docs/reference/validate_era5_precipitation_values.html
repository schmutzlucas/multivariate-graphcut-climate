validate_era5_precipitation_valuesR Documentation

Require physically valid daily ERA5 precipitation without clipping

Description

Require physically valid daily ERA5 precipitation without clipping

Usage

validate_era5_precipitation_values(values)

Arguments

values

Nonempty numeric daily precipitation vector/array in mm per day.

Value

List minimum, maximum and values_scanned after complete finiteness and nonnegativity checks. Any negative value, even a small one, fails explicitly; source investigation must precede any separately justified tolerance policy. Does not write or modify the supplied values or the original data archive.

Examples

stopifnot(validate_era5_precipitation_values(c(0, 1, 2))$maximum == 2)
