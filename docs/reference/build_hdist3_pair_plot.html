build_hdist3_pair_plotR Documentation

Render a pair of ordinary or restricted Hellinger maps

Description

Render a pair of ordinary or restricted Hellinger maps

Usage

build_hdist3_pair_plot(
  h_mmm,
  h_gc,
  lon,
  lat,
  limits = c(0, 0.5),
  palette_high = "#015a8c",
  left_title = "D-MMM",
  right_title = "GC-0.125",
  row_title = "Hellinger distance",
  show_x_title = TRUE
)

Arguments

h_mmm, h_gc

Numeric longitude x latitude D-MMM/GC score matrices in [0,1]; missing cells remain missing and values above limits are visually squished.

lon, lat

Regular cylindrical grid centres matching the matrices.

limits

Two finite increasing shared colour-scale endpoints.

palette_high

Colour at the upper endpoint of a white-to-colour gradient.

left_title, right_title

Scalar character method panel titles; empty hides.

row_title

Character or plotmath title for the shared row; empty hides.

show_x_title

Logical; include the Longitude axis title when TRUE.

Value

patchwork plot with equal-size maps, shared scale/legend and the manuscript coastline, crop and typography. No scores or files are modified.
