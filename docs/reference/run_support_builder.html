run_support_builderR Documentation

Build a separately reviewed candidate support using exact experiment scope

Description

Requires explicit MVGC_REBUILD_SUPPORTS=1 and external climate data. Configured models/year unions come from support_scope(): ERA5 includes its reference and 22 candidates in its two windows; PME uses its 15 models and one shared union of calibration plus all five targets, never leave-one-out-specific supports. Resource/read/decode settings are PME_RANGE_* environment overrides; output is MVGC_SUPPORT_OUTPUT_FILE or an outputs/supports candidate. Existing files are never overwritten. Restores the prior future plan when exiting.

Usage

run_support_builder(mode = c("era5", "pme"))

Arguments

mode

ERA5 or PME experiment profile.

Value

No scientific return value; writes an RDS containing named variable support arrays [0..359 longitude,-90..90 latitude,min/max] and rich metadata, and prints progress. Does not establish identity with the accepted support. See DATA_PREPROCESSING.md for the corrected-input workflow.
