read_fractional_variable_plan_blockR Documentation

Execute a prepared extraction plan for a subset of latitude positions

Description

Execute a prepared extraction plan for a subset of latitude positions

Usage

read_fractional_variable_plan_block(plan, lat_positions)

Arguments

plan

List returned as plan by extract_fractional_variable_data().

lat_positions

Nonempty integer positions within the plan's requested latitude selection, not positions in the original file axis.

Value

List with present/future lon x selected-latitude x selected-time cubes. Opens/closes the file for this block; retains original data units.
