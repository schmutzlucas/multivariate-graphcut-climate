summarize_ensemble_scoresR Documentation

Rank finite candidate and ensemble scores with smaller values preferred

Description

Rank finite candidate and ensemble scores with smaller values preferred

Usage

summarize_ensemble_scores(scores, mmm_value, gc_value)

Arguments

scores

Numeric vector with distinct nonempty candidate model names.

mmm_value, gc_value

Scalar D-MMM and GC scores; nonfinite values are unranked.

Value

One-row data frame of best/worst model identities and scores, unweighted type-7 ensemble quartiles, and minimum ranks among models plus both methods. No finite candidate scores yields missing summary fields.
