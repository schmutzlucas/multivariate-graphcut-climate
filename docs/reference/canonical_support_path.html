canonical_support_pathR Documentation

Translate archived support-path aliases without loading their contents

Description

Translate archived support-path aliases without loading their contents

Usage

canonical_support_path(path)

Arguments

path

Character vector of recorded support paths.

Value

Character vector replacing the two historical ranges/ aliases with bundled data/supports paths; other entries are unchanged. This does not select corrected supports or establish equivalence of their numerical values.

Examples

canonical_support_path("data/supports/pme_1950-2100.rds")
