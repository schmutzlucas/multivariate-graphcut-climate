weighted_fraction_improvedR Documentation

Measure the area with a strict reduction in absolute error

Description

Measure the area with a strict reduction in absolute error

Usage

weighted_fraction_improved(err_gc, err_mmm, weights)

Arguments

err_gc, err_mmm

Numeric GC and D-MMM errors with identical shape.

weights

Nonnegative weights of the same shape.

Value

Weighted fraction abs(err_gc) < abs(err_mmm) on common finite cells, or NA_real_ when none remain. Exact ties are not improvements.
