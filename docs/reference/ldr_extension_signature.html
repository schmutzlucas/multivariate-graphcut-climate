Description

Bind LDR extension caches to saved results, support, settings and input discovery

Usage

ldr_extension_signature(
  input,
  range_path,
  bundle,
  data_dir,
  cfg = article1_config()
)

Arguments

input, range_path

Existing source-bundle and common-support file paths.

bundle

Validated source bundle, including saved labels and scientific settings.

data_dir

Actual prepared data root used for NetCDF discovery.

cfg

Shared configuration, including the requested LDR threshold set.

Value

Signature list with fresh bundle/support/registry hashes, exact scientific settings, canonical code/native hashes and selected input file size/mtime records. Raw climate payloads are not rehashed here; legacy directory identity is explicitly weaker than a frozen registry plus the prepared-run payload checks.
