build_bias_4map_plotR Documentation

Assemble signed ERA5 mean-bias maps

Description

Assemble signed ERA5 mean-bias maps

Usage

build_bias_4map_plot(
  bias_tas_mmm,
  bias_tas_gc,
  bias_pr_mmm,
  bias_pr_gc,
  lon,
  lat
)

Arguments

bias_tas_mmm, bias_tas_gc

Signed temperature bias matrices (K), longitude x latitude.

bias_pr_mmm, bias_pr_gc

Signed precipitation bias matrices (mm/day), longitude x latitude.

lon, lat

Longitude and latitude cell centres in degrees, matching matrix axes.

Value

Gtable using unchanged temperature [-8,8] K and precipitation [-4,4] mm/day scales.
