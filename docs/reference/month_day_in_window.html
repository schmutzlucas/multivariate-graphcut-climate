month_day_in_windowR Documentation

Test membership in an inclusive seasonal month/day interval

Description

Test membership in an inclusive seasonal month/day interval

Usage

month_day_in_window(month, day, start_md, end_md, wraps_year_end)

Arguments

month

Numeric month vector of decoded dates.

day

Numeric day vector parallel to month.

start_md

Validated month/day start boundary.

end_md

Validated month/day end boundary.

wraps_year_end

Whether the interval joins December to January.

Value

Logical membership vector. Uses date ordering, not calendar-day arithmetic.

Examples

stopifnot(all(month_day_in_window(c(12,1),c(31,1),c(12,1),c(2,28),TRUE)))
