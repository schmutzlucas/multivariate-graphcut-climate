find_matching_netcdf_fileR Documentation

Resolve one prepared NetCDF input for a model and variable

Description

An active MVGC_INPUT_REGISTRY takes precedence and never falls back to directory discovery. Otherwise search data_dir/model/variable; with multiple files choose the smallest filename year span covering the request. A sole file is returned without proving its dates; extraction audits it later.

Usage

find_matching_netcdf_file(data_dir, model, variable, required_years)

Arguments

data_dir

Root directory used only without an active input registry.

model

Single model identifier, e.g. ERA5.

variable

Prepared variable identifier, e.g. pr.

required_years

Nonempty integer vector of requested years.

Value

One path. Missing/ambiguous coverage raises an error; choosing among multiple covering files emits a warning.
