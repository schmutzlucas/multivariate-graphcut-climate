Description

Record the registry and support identity for a result or checkpoint

Usage

experiment_input_provenance(support)

Arguments

support

Path to one histogram-support RDS.

Value

List containing paths, freshly calculated registry/support SHA-256 and an input-identity description. Payload hashes are not recalculated here; directory-only legacy selection is explicitly weaker than a frozen registry.
