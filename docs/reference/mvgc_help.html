mvgc_helpR Documentation

Open a generated function reference without installing an R package

Description

Open a generated function reference without installing an R package

Usage

mvgc_help(topic, source = NULL, open = interactive())

Arguments

topic

Function name, as a single character string.

source

Optional repository-relative source file to disambiguate helpers with the same name in multiple modules.

open

Logical; open the HTML page in a browser. Defaults to interactive().

Details

Run Rscript tools/build_reference_docs.R after editing roxygen blocks. Plain sourcing does not register standard R help databases, so ?topic is not guaranteed to find a repository-local function. This helper is explicit and leaves the scientific project as a script-based repository.

Value

Absolute HTML path invisibly. Errors if no unique generated page exists.

Examples

if (file.exists("docs/reference/topics.csv")) {
  mvgc_help("hellinger_distance", open = FALSE)
}
