reproduction_profileR Documentation

Resolve the compact numerical inputs for a named article reproduction profile

Description

Resolve the compact numerical inputs for a named article reproduction profile

Usage

reproduction_profile(
  profile = Sys.getenv("MVGC_REPRODUCTION_PROFILE", "current")
)

Arguments

profile

Current (completed October reruns) (the accepted publication cohort). MVGC_REPRODUCTION_PROFILE selects it.

Value

Named list with profile, paths, environment override names and cohort manifests. No file is read, directory created or experiment configured.
