parse_time_origin_dateR Documentation

Extract a Gregorian origin date from a CF units string

Description

Used for the explicitly estimated fallback range, not for exact non-Gregorian date decoding. Time of day is discarded. Intended inputs have UTC origins; arbitrary numeric time-zone offsets are not supported by this parser.

Usage

parse_time_origin_date(time_units)

Arguments

time_units

One units string containing since and a date origin.

Value

Scalar R Date; an unparseable origin raises an error.

Examples

parse_time_origin_date("days since 1950-01-01 00:00:00 UTC")
