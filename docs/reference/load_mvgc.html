load_mvgcR Documentation

Load the reusable Article 1 functions without running an experiment

Description

Load the reusable Article 1 functions without running an experiment

Usage

load_mvgc(envir = parent.frame())

Arguments

envir

Environment in which to define configuration and reusable functions; defaults to the caller. Existing definitions of the same names are replaced.

Value

Character vector of sourced module paths, invisibly. Paths are relative to the repository root. Does not download data or source experiment entry points.

Examples

e <- new.env()
load_mvgc(e)
stopifnot(exists("hellinger_distance", envir=e, inherits=FALSE))
