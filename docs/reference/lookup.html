lookupR Documentation

Look up one unrounded ERA5 statistic by its scientific identity

Description

Look up one unrounded ERA5 statistic by its scientific identity

Usage

lookup(method, vars, metric, tau = NA_real_, name = "weighted_mean")

Arguments

method, vars, metric

Scalar internal method, variable-set and metric-type keys.

tau

Scalar LDR threshold in (0,1), or NA_real_ for an ordinary metric.

name

Scalar metric-name key; default weighted_mean.

Value

One finite numeric value from caller-environment era. Missing or ambiguous rows raise an error; no first-row fallback or rounding occurs.
