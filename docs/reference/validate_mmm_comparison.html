validate_mmm_comparisonR Documentation

Validate matched reference and D-MMM PMF arrays

Description

Validate matched reference and D-MMM PMF arrays

Usage

validate_mmm_comparison(pdf_ref, pdf_d_mmm)

Arguments

pdf_ref, pdf_d_mmm

Numeric lon x lat x bins arrays on identical supports.

Value

TRUE invisibly; invalid shape, masses or normalisation raise an error. No missing value replacement, renormalisation or score adjustment is performed.
