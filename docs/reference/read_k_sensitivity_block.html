read_k_sensitivity_blockR Documentation

Read one model's calibration latitude block for resolution sensitivity

Description

Read one model's calibration latitude block for resolution sensitivity

Usage

read_k_sensitivity_block(model_plan, variables, lat_positions)

Arguments

model_plan

Model entry from prepare_k_sensitivity_plans().

variables

Ordered pr/tas/psl identifiers.

lat_positions

Positions in the requested latitude vector, not file-axis indices.

Value

Named list of lon x block-lat x time cubes; pr uses the production shared nonnegative QC then log1p; tas/psl remain in prepared units. Opens/closes each variable file independently, including on read errors. Does not regrid data.
