map_fractional_window_to_year_lengthR Documentation

Map a non-leap seasonal interval proportionally onto a model year

Description

Uses 1 + floor((start-1)*L/365) and floor(end*L/365), clamped to 1..L. A whole-year request always maps to every slot. A wrapped interval is the union of the end and start segments within each selected calendar year, not a season reassigned to the following year's label.

Usage

map_fractional_window_to_year_length(
  year_length,
  start_ref_doy,
  end_ref_doy,
  wraps_year_end
)

Arguments

year_length

Positive integer model/empirical year length L.

start_ref_doy

One-based start day on the 365-day reference calendar.

end_ref_doy

One-based end day on the same reference calendar.

wraps_year_end

Logical scalar indicating an interval across December/January.

Value

List of integer-like scalars start_mod and end_mod.

Examples

stopifnot(map_fractional_window_to_year_length(360,1,365,FALSE)$end_mod == 360)
