select_full_year_indicesR Documentation

Plan a full-year support selection on the experiment's requested grid

Description

Plan a full-year support selection on the experiment's requested grid

Usage

select_full_year_indices(
  nc_obj,
  file_path,
  variable,
  years,
  lon,
  lat,
  strict_time_checks,
  season_selection_mode,
  time_decode_mode,
  requested_year_policy
)

Arguments

nc_obj

Open NetCDF handle, not closed here.

file_path

Input path used for coverage hints and diagnostic messages.

variable

Three-dimensional prepared variable name.

years

Requested year vector; may contain disjoint experiment windows.

lon, lat

Requested coordinate vectors, matched without interpolation.

strict_time_checks

Whether to enforce legacy daily-mapping assumptions.

season_selection_mode

Auto, exact_month_day, or fractional. The selected seasonal boundaries are always January 1 through December 31.

time_decode_mode

Auto, helpers_cf, or empirical decoding.

requested_year_policy

Warn or stop for unavailable/incomplete years under the legacy mapping; this is not independent proof of complete calendar dates.

Value

List with selected indices, per-year summary, calendar/selection mode, original dimension metadata and matched file-coordinate indices.
