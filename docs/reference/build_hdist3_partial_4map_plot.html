build_hdist3_partial_4map_plotR Documentation

Assemble full-distribution and LDR ERA5 maps

Description

Assemble full-distribution and LDR ERA5 maps

Usage

build_hdist3_partial_4map_plot(
  h_mmm,
  h_gc,
  partial_h_mmm,
  partial_h_gc,
  lon,
  lat,
  tau_label
)

Arguments

h_mmm, h_gc

Longitude x latitude full-distribution Hellinger distance matrices.

partial_h_mmm, partial_h_gc

Longitude x latitude non-renormalised LDR Hellinger score matrices.

lon, lat

Longitude and latitude cell centres in degrees, matching matrix axes.

tau_label

Numeric-character LDR probability-mass threshold; accepted layout requires 0.01.

Value

Gtable for full Hellinger distance and non-renormalised LDR Hellinger score; threshold must be 0.01.
