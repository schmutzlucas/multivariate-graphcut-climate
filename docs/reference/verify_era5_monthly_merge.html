verify_era5_monthly_mergeR Documentation

Check every merged ERA5 daily value against its signed monthly input

Description

Check every merged ERA5 daily value against its signed monthly input

Usage

verify_era5_monthly_merge(final_nc, expected_keys, sources)

Arguments

final_nc

Open caller-owned ncdf4 handle for the merged daily pr product.

expected_keys

Complete ordered YYYY-MM-DD keys already verified for final_nc.

sources

Ordered monthly records with YYYYMM month, file, bytes and sha256.

Value

Total compared values invisibly. Requires every expected month exactly once, fresh monthly payload hashes and matching dates/coordinates/units. Uses exact decoded-value equality, not a numerical tolerance or summary mean. Opens/closes monthly handles and reads at most one monthly cube at a time; leaves final_nc open. Requires the NetCDF helpers repair_axis/repair_equal definitions, loaded explicitly by the UTC validation entry point.
