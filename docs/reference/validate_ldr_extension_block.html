validate_ldr_extension_blockR Documentation

Validate a complete numerical LDR latitude-block payload

Description

Validate a complete numerical LDR latitude-block payload

Usage

validate_ldr_extension_block(maps, keys, lambda_keys, models, grid)

Arguments

maps

Named threshold list, each with MMM reference maps and GC lambda/reference maps.

keys, lambda_keys

Exact threshold and lambda key vectors expected in this block.

models

Ordered held-out reference names.

grid

Integer longitude/block-latitude dimensions.

Value

TRUE invisibly; missing/duplicate identities, wrong shapes and nonfinite, negative or above-one scores raise an error. Missing values are never approved.
