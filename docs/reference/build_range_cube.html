build_range_cubeR Documentation

Read the common PME support and reorder longitude to the graph-cut grid

Description

Read the common PME support and reorder longitude to the graph-cut grid

Usage

build_range_cube(range_file_path, variables)

Arguments

range_file_path

RDS with a ranges list in 0:359 longitude / -90:90 latitude order.

variables

Requested ordered variable identifiers, normally pr/tas/psl.

Value

Array [360,181,variables,2] in -180:179 longitude order with dimnames. Reads existing bounds, never estimates per-reference supports. Requires each variable entry to be exactly [360,181,2]; later PMF validation checks finite, strictly increasing bounds and the prepared-support resolver checks provenance.
