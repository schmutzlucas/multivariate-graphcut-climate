write_k_sensitivity_outputsR Documentation

Save the Article 1 histogram-resolution diagnostic and its numerical outputs

Description

Save the Article 1 histogram-resolution diagnostic and its numerical outputs

Usage

write_k_sensitivity_outputs(result, output_dir)

Arguments

result

Result list from run_k_sensitivity(), including a finite k=8 score.

output_dir

Output directory to create if absent. Fixed diagnostic filenames may overwrite earlier renders; production controllers require a new run directory. Validation precedes all writes, including CSV/RDS output.

Value

Paths to global CSV, cellwise RDS, PNG and PDF, invisibly. Writes a 29 x 18 cm figure at 300 dpi, with actual scope annotations. Does not change production k, launch an experiment, or imply scientific approval of a run.
