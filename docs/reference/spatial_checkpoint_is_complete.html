spatial_checkpoint_is_completeR Documentation

Check a spatial-sensitivity checkpoint for scientific identity and success

Description

Check a spatial-sensitivity checkpoint for scientific identity and success

Usage

spatial_checkpoint_is_complete(record, lambda, signature, grid, n_models)

Arguments

record

Deserialised checkpoint list, or malformed value to reject.

lambda

Expected scalar nonnegative numeric lambda.

signature

Exact expected scientific/input signature list.

grid

Expected longitude/latitude dimensions, a two-element integer vector.

n_models

Positive integer candidate-model count.

Value

TRUE only for a complete matching checkpoint with finite integer labels in range and finite nonnegative native data/smooth energies. Malformed or unsuccessful payloads return FALSE, never partial numerical approval.
