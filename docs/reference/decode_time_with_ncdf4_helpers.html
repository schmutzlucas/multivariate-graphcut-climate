decode_time_with_ncdf4_helpersR Documentation

Adapt optional ncdf4.helpers time decoding to R Date

Description

Tries three helper calling conventions and several Date coercions. Conversion can fail for dates unrepresentable by R's Gregorian Date (e.g. February 30). The caller chooses whether failure is fatal or permits a documented fallback.

Usage

decode_time_with_ncdf4_helpers(nc_obj, time_dim_name)

Arguments

nc_obj

Open NetCDF handle, not closed here.

time_dim_name

Time dimension name supplied to the optional helper.

Value

List with Date vector date_values, helper_method and helper_result_class; raises an error if all attempts fail.
