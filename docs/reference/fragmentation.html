fragmentationR Documentation

Count differently labelled edges on the graph-cut cylindrical grid

Description

Count differently labelled edges on the graph-cut cylindrical grid

Usage

fragmentation(labels)

Arguments

labels

Numeric matrix of positive finite integer labels indexed longitude x latitude, with at least three longitude and two latitude cells.

Value

One-row data frame with longitude/latitude/different/total edge counts and fragmentation_pct. Each four-connected edge is counted once; longitude wraps, latitude does not, polar rows remain, and no area/energy weighting occurs.
