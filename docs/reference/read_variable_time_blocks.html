read_variable_time_blocksR Documentation

Read selected NetCDF records in longitude-latitude-time order

Description

Reads a bounding spatial rectangle per contiguous unique-time block, permutes original file axes, and subsets the requested spatial coordinates. It does not regrid, convert units, log-transform precipitation, or infer missing values. Finite negative precipitation is set to zero immediately after each disk read.

Usage

read_variable_time_blocks(
  nc_obj,
  variable,
  dimension_info,
  lon_indices,
  lat_indices,
  time_indices
)

Arguments

nc_obj

Open NetCDF handle, owned and closed by the caller.

variable

Name of the three-dimensional variable to read.

dimension_info

Axis metadata from get_variable_dimension_info().

lon_indices, lat_indices

Nonempty positive integer positions in original file axes. Requested order and repetitions are retained.

time_indices

Positive integer time positions, possibly unordered or repeated. Empty input is allowed; positions outside the file are rejected.

Value

Numeric array longitude x latitude x requested time. Singleton axes remain present; time ordering/repetitions exactly follow the request.
