infer_time_structure_dailyR Documentation

Build legacy daily time-selection metadata and completeness diagnostics

Description

Supports helper-based or empirical mapping, with Gregorian dates decoded from UTC offsets and non-Gregorian empirical years inferred from filename start plus day offsets. Full-year non-Gregorian files must start on January 1.

Usage

infer_time_structure_daily(
  nc_obj,
  file_path,
  time_dim_name,
  calendar,
  required_years,
  strict_time_checks = TRUE,
  time_decode_mode = c("auto", "helpers_cf", "empirical"),
  requested_year_policy = c("warn", "stop")
)

Arguments

nc_obj

Open NetCDF handle, not closed here.

file_path

Path containing a date-range hint, used in diagnostics.

time_dim_name

Time dimension name.

calendar

Canonical CF calendar name.

required_years

Integer vector of requested years.

strict_time_checks

Whether invalid ordering/fractional non-Gregorian offsets raise errors; gaps may still warn and receive per-year checks.

time_decode_mode

One of auto, helpers_cf (no decode fallback), empirical.

requested_year_policy

Warn or stop when requested years fail the active mapping's completeness test. Defaults to warn, unchanged from production.

Details

Important: Gregorian/helper is_full_year uses modal observed counts within leap/non-leap groups, not only theoretical calendar lengths. A repeated missing-day pattern can therefore be classified full under the legacy mapping. declared_calendar_mismatch exposes this; it is not proof of complete dates. Corrected-data preparation separately verifies exact CF date coverage. Warn policy preserves the historical experiment behaviour; it does not repair or approve missing data. time_phase is a legacy NA placeholder.

Value

List containing backend/fallback diagnostics, year_table, file coverage, and per-record timestep_year, timestep_slot and timestep_doy. Slots can be observed-record ranks, not true DOYs.
