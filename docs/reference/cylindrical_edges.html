cylindrical_edgesR Documentation

Enumerate four-neighbour edges on a longitude-periodic grid

Description

Enumerate four-neighbour edges on a longitude-periodic grid

Usage

cylindrical_edges(nlon, nlat)

Arguments

nlon

Integer longitude count, at least three.

nlat

Integer latitude count, at least one.

Value

Two-column integer matrix p/q of one-based flattened pixel IDs, one row per undirected edge. Longitude varies fastest. Every row wraps east-west; latitude never wraps and no diagonal edge is added.

Examples

cylindrical_edges(3, 2)
