checkpoint_is_compatibleR Documentation

Check scientific identity and successful numerical payload of a PME checkpoint

Description

Check scientific identity and successful numerical payload of a PME checkpoint

Usage

checkpoint_is_compatible(
  checkpoint_file,
  period_row,
  calibration_years,
  period_role,
  lambda_keys,
  tau_keys,
  expected_model_names,
  range_sources,
  partial_h_definition,
  expected_settings = pme_scientific_settings()
)

Arguments

checkpoint_file

Existing checkpoint path, or a missing candidate path.

period_row

One-row table describing the requested target period.

calibration_years

Exact requested integer calibration years.

period_role

Scientific calibration/projection role identifier.

lambda_keys, tau_keys

Ordered smoothness and ell_LDR nested-list keys.

expected_model_names

Full ordered held-out/candidate model list.

range_sources

Exact support path used by this computation.

partial_h_definition

Recorded LDR evaluation-definition string.

expected_settings

Signature from pme_scientific_settings(), updated with the actual numerical lambda/threshold grids when run-specific overrides apply.

Value

TRUE only for matching, successful finite score/label payloads. Missing, old-signature, failed, malformed or different-input checkpoints return FALSE. Ordinary comments alone do not invalidate otherwise identical checkpoints.
