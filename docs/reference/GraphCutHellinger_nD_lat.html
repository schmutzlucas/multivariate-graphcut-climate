GraphCutHellinger_nD_latR Documentation

Optimise latitude-weighted cylindrical graph-cut model labels

Description

Fit labels using calibration Hellinger unary costs and target-period PMF seam costs. Article 1 uses the pinned custom gcoWrapR solver and swap(-1).

Usage

GraphCutHellinger_nD_lat(
  pdf_models_future,
  h_dist,
  weight_data,
  weight_smooth,
  nBins,
  lat,
  seed,
  verbose,
  rebuild
)

Arguments

pdf_models_future

Normalised target PMFs, dimensions longitude x latitude x joint bins x candidate models. Longitude must be periodic and ordered consistently; the native grid requires at least 3 x 2 cells and 2 labels.

h_dist

Nonnegative calibration Hellinger distances, longitude x latitude x models.

weight_data

Nonnegative scalar multiplying the unary term, normally 1.

weight_smooth

Nonnegative scalar lambda multiplying the seam term.

nBins

Total number of joint bins, normally 512 for 8 x 8 x 8, not the number of bins along one variable.

lat

Latitude centres in degrees north, one per array latitude row.

seed

Seed for the pseudo-random initial labels; Article 1 fixes seed 1.

verbose

Logical; print native solver and progress information.

rebuild

Logical; force recompilation of the native callback functions.

Details

R labels become zero-based for C++ and one-based on return. Unary costs use cos(latitude); an edge uses mean endpoint latitude weight times the sum of endpoint Hellinger differences between its two selected models. Longitude wraps east-west; latitude has no polar wrap. The pinned custom solver revision is enforced by production entry points, not this low-level API. Native callbacks deliberately accumulate in float precision. This function resets the process RNG kind/state and uses a locally converged swap solution; it does not promise a global optimum for arbitrary multi-label problems.

Value

List with label_attribution, a one-based longitude x latitude matrix, and 'Data and smooth cost', the native unary/seam energies. Runtime is printed when verbose but is not included in the returned list.

Examples


p <- array(0.5, c(3, 2, 2, 2))
h <- array(0.1, c(3, 2, 2))
fit <- GraphCutHellinger_nD_lat(p, h, 1, 0.125, 2, c(-30, 30),
                               seed = 1, verbose = FALSE, rebuild = FALSE)
dim(fit$label_attribution)
