hellinger_distanceR Documentation

Compute the Hellinger distance between two PMFs

Description

Compute the Hellinger distance between two PMFs

Usage

hellinger_distance(p, q)

Arguments

p, q

Numeric normalised PMFs on the same ordered bins.

Value

Scalar sqrt(sum((sqrt(p) - sqrt(q))^2) / 2), between zero and one.

Examples

hellinger_distance(c(1, 0), c(0, 1))
