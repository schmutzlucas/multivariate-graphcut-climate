# Contributing

Keep scientific definitions, input identities and reported results explicit.
Run the reusable tests and compact reproduction before proposing changes.
Do not overwrite frozen publication data or graphics. A changed scientific
algorithm, support scope, bin convention, preprocessing policy or solver requires
separate scientific review and a new numerical cohort. Document R parameters,
return values, dimensions, units and side effects adjacent to functions using
roxygen2. Meaningful examples are encouraged for public interfaces; artificial
examples for private helpers are unnecessary.

Keep internal investigations, test logs, development diagnostics, credentials,
data downloads and institutional paths outside the publication source/history.
Only purpose-written scientific documentation and reusable tests belong here.
The release is built from an explicit approved-file manifest, never a directory dump.
